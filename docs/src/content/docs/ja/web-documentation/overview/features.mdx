Web Documentation プラットフォームは、技術文書の作成・閲覧・保守をより簡単にするための機能一式を提供しています。

## MDX によるコンテンツ

ドキュメントは **MDX** で書かれており、おなじみの Markdown 構文とコンポーネントを埋め込む機能を組み合わせています。

* Markdown 構文（見出し、リスト、テーブル、引用など）を完全にサポート。
* コンテンツ内に直接カスタムコンポーネント（例：`<Tabs>`、`<TabItem>`）を埋め込むことが可能。
* 各ページは SEO とナビゲーションのために独自の frontmatter（`title`、`description`）を持つ。

## コードブロックと行番号

コードブロックは Expressive Code によって提供されており、以下をサポートしています。

* 多くのプログラミング言語に対応したシンタックスハイライト。
* 特定の行を参照する必要がある場合の行番号表示（`showLineNumbers`）。
* ファイルや文脈を説明するためのコードブロックタイトル（`title="..."`）。

## Mermaid 図

このプラットフォームは **Mermaid** を統合しており、コードブロックから直接図を描画できます。

* フローチャート、シーケンス図、クラス図など。
* `@mermaid-js/mermaid-zenuml` プラグインによる ZenUML 図のサポート。
* 外部の作図ツールを使わずに、図をページ内で直接レンダリング。

## コールアウト

`:::note`、`:::tip`、`:::caution`、`:::danger` という構文により、読者を本文の流れから逸らすことなく重要な情報を強調できます。

## 拡張されたテーブル

カスタム remark プラグインにより、Markdown テーブルは `[width=...]` 構文で拡張され、必要に応じて列幅を制御できます。

## 全文検索

ドキュメント全体をコンテンツで検索できるため、読者は各セクションを順に閲覧する代わりに、目的のキーワードを含むページへ素早く移動できます。

## 多言語対応

このプラットフォームは複数の言語をサポートしています。

| 言語        | コード |
| ----------- | ------ |
| Tiếng Việt  | `vi`   |
| English     | `en`   |
| 中文        | `zh`   |
| 日本語      | `ja`   |

各言語は独自のコンテンツディレクトリを持ち、ロケールごとに翻訳を独立して管理できます。

## ライト・ダークテーマ

ユーザーの選択やシステム設定に応じて、インターフェースはライトテーマとダークテーマを自動的に切り替えます。

## レスポンシブ対応

インターフェースはデスクトップ、タブレット、モバイルで見やすく表示されるよう最適化されており、幅の広いテーブルや長いコードブロックにも対応しています。

## ナビゲーションと目次

* ドキュメントのフォルダ構成に基づいて自動生成されるサイドバー（`autogenerate`）。
* ページ内の見出しから自動生成される目次（Table of Contents）により、各セクションへ素早く移動可能。

## Git によるバージョン管理

ドキュメントはリポジトリ内に MDX ファイルとして保存されており、次のことが可能です。

* コンテンツ変更の履歴を追跡する。
* プルリクエストを通じて、コードと同じようにドキュメントの変更をレビューする。
* 必要に応じて過去のバージョンを復元・比較する。
