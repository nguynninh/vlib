## 1.0.0

### 追加

- [タイポグラフィ](/ja/web-documentation/ui/typography) ページ:見出し、段落、太字、斜体、取り消し線、インラインコード、リスト(順不同、順序付き、タスク)、引用、水平線、リンク、画像、改行、特殊文字のエスケープ、技術文書におけるテキスト表現のルールについて解説。

### 更新

- [はじめに](/ja/web-documentation/overview/introduction):内容を全面的に書き直し、残っていたサンプル内容(決済ゲートウェイの統合)から、Web Documentation プラットフォームについての正しい紹介に変更。
- [機能](/ja/web-documentation/overview/features):各機能(MDX、コードブロック、Mermaid、コールアウト、拡張テーブル、全文検索、多言語対応、ライト/ダークテーマ、レスポンシブ対応、ナビゲーション、Git によるバージョン管理)について詳細な内容を追加。
- [技術スタック](/ja/web-documentation/overview/tech-stack):技術スタックの表、カスタム Markdown プラグイン、i18n 設定、フォルダ構成、ビルド・デプロイ手順を追加。
- [Media & Files](/ja/web-documentation/ui/media_file):GitHub Releases を直接指していたサンプルの画像・動画・ファイルのリンクを `BASE_STORAGE` 変数に置き換え、ストレージの参照先を変更しやすくした。
- ビルド設定(`astro.config.mjs`、`remark-media-options.mjs`):`PORT` 変数を読み込んで開発サーバーのポートを設定し、ビルド時にメディアリンク内の `BASE_STORAGE` トークンを `.env` の実際の値に自動的に置き換えるようにした。
