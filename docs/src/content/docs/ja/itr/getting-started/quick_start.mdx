**Interactive SDK** をアプリに導入し、最初のオーバーレイを表示するためのクイックガイドです。

:::caution
まだ[概要](/ja/itr/getting-started/overview)を読んでいない場合は、先に目を通してSDKの全体アーキテクチャを理解することをおすすめします。
:::

## 1. プラットフォームを選択

お使いのプラットフォームに応じた詳細な統合ドキュメントを選択してください。

- **Android** → [インストールと統合](/ja/itr/android/installation_integration) を参照
- **iOS** → [インストールと統合](/ja/itr/ios/installation_integration) を参照

## 2. 共通のステップ

1. **SDKを追加**: プロジェクトに追加します（ソースモジュールまたは `.aar`/フレームワークファイル）。
2. **初期化**: 動画再生画面でオーバーレイ管理コンポーネント（Androidの場合は例えば `OverlayManager`）を初期化します。
3. **リアルタイム接続**: トークン初期化関数（`initToken`）を呼び出し、ルームに参加（`joinRoom`）してInteractiveサーバーからのイベントを受信します。
4. **オーバーレイを配置**: プレーヤーの上に、動画表示領域に重ねるオーバーレイビューを宣言します。
5. **コールバックを監視**: `NEED_LOGIN` などの状態、ソケット状態の変化、ユーザーからのインタラクションイベントを処理します。
6. **テスト**: ステージング環境/Interactiveサーバーで動作確認を行い、オーバーレイが正しく表示され、トラッキングのemit-ackが機能することを確認します。

## 3. 次のステップ

- 各コンポーネントがどのように連携するかを理解するために、[Interactive SDKアーキテクチャ](/ja/itr/android/sdk_interactive_architecture) を参照してください。
- インタラクションセッションのライフサイクルを把握するために、[詳細な動作フロー](/ja/itr/android/detailed_workflow) を参照してください。
- 各関数/コールバックの詳細が必要な場合は、[APIリファレンス](/ja/itr/android/api_reference) を参照してください。
- 統合中に問題が発生した場合は、[よくあるエラー](/ja/itr/android/error) を参照してください。
