## 1.0.1

### 変更

- Web Documentation セクション全体を `/web-documentation` から `/internal/web-documentation` に移動し、公開エリア(SDK Game、Interactive ドキュメント、私たちについて)から切り離した。
- サイトのデフォルトホームページ(`index.mdx`)も `/internal` 配下に移動し、内部エリア専用のウェルカムページとして機能するように変更。公開エリア(`/vi`、`/en`、`/zh`、`/ja`)は現在 SDK Game に直接遷移する。
- 上部のナビゲーションバーは表示中のエリアによって内容が変わるようにした:公開エリアでは3項目、`/internal` 内では「Webドキュメント」の1項目のみを表示。
- 左上の VLive ロゴのリンク先を、ドキュメントのホームページから公式サイト `https://vtvlive.vn/` に変更。
- Web Documentation の各ページ(タイポグラフィ、テーブル、コードブロック、Media & Files、はじめに、機能、技術スタックなど)内のすべての内部リンクを、新しい `/internal/web-documentation/...` パスに更新。
- 「私たちについて」ページを英語・中国語・日本語に翻訳(これまではこれら3言語で未翻訳の警告付きベトナム語フォールバック内容が表示されていた)。

### 追加

- `/internal/*` 配下のすべてのページに `<meta name="robots" content="noindex, nofollow">` タグを追加し、`robots.txt` でもクローラーをブロックするようにした。内部エリアであり検索エンジンに公開しないため。
- 短縮パス向けのリダイレクトを追加:`/<locale>` → SDK Game の概要ページ、`/<locale>/internal/web-documentation` → 概要/はじめにページ。

### 修正

- 公開エリアと `internal` の境界にあった前へ/次へページネーションの不具合を修正:これまで Interactive ドキュメントの最終ページが、公開ナビゲーションから非表示になっている Web Documentation へ自動的に遷移していたが、両端でリンクを切断した。
- ホームページが1階層深い `internal/` フォルダへ移動したことで発生していた画像の相対パス(`houston.webp`)の誤りを修正。

## 1.0.0

### 追加

- [タイポグラフィ](/ja/internal/web-documentation/ui/typography) ページ:見出し、段落、太字、斜体、取り消し線、インラインコード、リスト(順不同、順序付き、タスク)、引用、水平線、リンク、画像、改行、特殊文字のエスケープ、技術文書におけるテキスト表現のルールについて解説。

### 更新

- [はじめに](/ja/internal/web-documentation/overview/introduction):内容を全面的に書き直し、残っていたサンプル内容(決済ゲートウェイの統合)から、Web Documentation プラットフォームについての正しい紹介に変更。
- [機能](/ja/internal/web-documentation/overview/features):各機能(MDX、コードブロック、Mermaid、コールアウト、拡張テーブル、全文検索、多言語対応、ライト/ダークテーマ、レスポンシブ対応、ナビゲーション、Git によるバージョン管理)について詳細な内容を追加。
- [技術スタック](/ja/internal/web-documentation/overview/tech-stack):技術スタックの表、カスタム Markdown プラグイン、i18n 設定、フォルダ構成、ビルド・デプロイ手順を追加。
- [Media & Files](/ja/internal/web-documentation/ui/media_file):GitHub Releases を直接指していたサンプルの画像・動画・ファイルのリンクを `BASE_STORAGE` 変数に置き換え、ストレージの参照先を変更しやすくした。
- ビルド設定(`astro.config.mjs`、`remark-media-options.mjs`):`PORT` 変数を読み込んで開発サーバーのポートを設定し、ビルド時にメディアリンク内の `BASE_STORAGE` トークンを `.env` の実際の値に自動的に置き換えるようにした。
