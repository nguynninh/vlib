SDK Game は各モバイルプラットフォームごとに個別に構築される一方、一部の Backend サービスおよびサードパーティサービスを共通で利用しています。

## 概要表

| コンポーネント          | 技術                                 | 役割                                                      |
| ---------------------- | ------------------------------------ | --------------------------------------------------------- |
| Android プラットフォーム | Java                                  | Android 向け SDK 実装言語                                    |
| iOS プラットフォーム    | Objective-C / Swift                  | iOS 向け SDK 実装言語                                        |
| アカウント認証           | OIDC V2                              | ログインおよび SDK の API/IAP に使用される認証標準              |
| 動的設定                | 内部 BE API                           | ゲームにリアルタイム設定を提供                                  |
| 動的設定                | Firebase Remote Config               | バージョンごとの動的設定ソースを追加提供                           |
| OTP 認証                | 内部 BE API                           | ユーザーのメールアドレス・電話番号を認証                            |
| イベントトラッキング       | トラッキング用 BE API                  | ゲームハブ、通知、play_time などのイベントを記録                    |

## Android プラットフォーム

Android 版 SDK は **Java** で記述されており、SDK ライブラリを通じてゲームプロジェクトに直接統合されます。設定、統合、Backend エラーコード、イベントの emit/ack フローに関する詳細なドキュメントが用意されています。

## iOS プラットフォーム

iOS 版 SDK は **Objective-C**（Swift サポート付き）で記述されており、統合ドキュメント、トラッキングガイド、使用しているサードパーティライブラリ、および SDK の各バージョンごとの更新ノートを提供します。

## 認証：OIDC V2

SDK で使用される API/IAP は **OIDC V2** をベースに構築されており、ゲーム間および SDK バージョン間で一貫した認証メカニズムを保証します。

## 動的設定

動的設定は以下の 2 つのソースを組み合わせて構成されます。

* **内部 BE API** — VTV Live の Backend チームが運用
* **Firebase Remote Config** — Google のサービスで、ビルドを再リリースすることなくリアルタイムに設定を調整できるようサポート

## イベントトラッキング

各種イベント（ゲームハブ、通知、play_time など）はトラッキング用 BE API に送信され、各イベントのフローを説明するドキュメントと、広告最適化に使用する MKT イベントに関する注記が併せて提供されます。
