## SDK Game について

**SDK Game** は、**VTV Live** エコシステム上で運用されるゲーム向けの統合 SDK であり、ログイン、認証、イベントトラッキング、および Backend システムからの動的設定受信の各フローをあらかじめ提供します。

SDK を利用することで、ゲーム開発チームはプラットフォーム共通の業務（アカウント、通知、マーケティングイベントなど）をプロジェクトごとにゼロから構築する必要がなくなり、統合にかかる時間を短縮できます。

## 目的

SDK Game は以下を目的として構築されています。

* ゲーム間でのアカウント統合、ログイン、認証（OTP、パスワード忘れ）フローの標準化
* BE API および Firebase Remote Config からの動的設定受信メカニズムの提供
* ゲームハブ、通知、および MKT 最適化に使用するイベントのトラッキングサポート
* ゲーム内業務（ギフト受け取り、ユーザー情報更新など）で共通利用できる API/IAP の提供
* 統合時間の短縮と、Android・iOS プラットフォーム間の一貫性の確保

## 対応プラットフォーム

SDK Game は現在、以下の 2 つの主要プラットフォームをサポートしています。

```text
SDK Game
│
├── Android (Java)
└── iOS (Objective-C / Swift)
```

各プラットフォームには、統合ドキュメント、API ドキュメント、イベントフロー説明ドキュメントがそれぞれ用意されており、両プラットフォーム間で内容が同期するよう並行して作成されています。

## ドキュメント構成

SDK Game のドキュメントは、主に以下のセクションで構成されています。

* **概要** — 紹介、機能、使用技術
* **Android / iOS** — プラットフォームごとの設定・SDK 統合ガイド
* **SDK 機能** — OTP、パスワード忘れ、ギフト受け取り、動的設定など各機能の詳細説明
* **統合ドキュメント / API / イベントフロー** — 統合作業で使用する完全なリファレンスドキュメント

## 対象読者

本ドキュメントは主に以下の方を対象としています。

* SDK Game を Android または iOS プロジェクトに統合する開発者
* アカウント、トラッキング、動的設定のフローをテストする QA
* 広告最適化のためにイベントフローを理解する必要がある運用/MKT チーム
