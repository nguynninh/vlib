SDK Game は、VTV Live エコシステム内のゲームにおけるアカウント業務とトラッキングを標準化するための一連の機能を提供します。

## OTP 認証

ユーザーのメールアドレスおよび電話番号を OTP コードで認証する機能をサポートし、ゲーム内の登録やアカウント情報変更の各フローで共通して利用できます。

## パスワード忘れ

完全なパスワード再設定フローを提供し、ユーザーがゲームを離れることなくアカウントを復旧できるようにします。

## BE API および Firebase Remote Config による動的設定

SDK はゲームの実行中にリアルタイムで動的設定を受け取ることができ、以下を組み合わせて利用します。

* システム内部の BE API
* Firebase Remote Config

これにより、設定の変更（機能の有効化/無効化、運用パラメータなど）をゲームのビルドを再リリースすることなく適用できます。

## ゲーム内ギフト受け取り

共通 API を通じたゲーム内ギフト受け取りフローをサポートし、複数のゲームが同じギフトプログラムを利用する際の一貫性を確保します。

## ユーザー情報更新のリクエスト

ゲーム参加時に不足しているユーザー情報を自動的にチェックし、更新を促すことで、後続の業務に必要なアカウントデータの完全性を確保します。

## ゲームハブのトラッキング

ユーザーとゲームハブ間のインタラクションイベントを記録し、行動分析やプロダクト運用に活用します。

## 通知の追跡

ゲームに送信された通知（notification）に対するユーザーの受信状況およびインタラクション状況を追跡します。

## play_time イベント

`play_time` イベントの記録ロジックを更新し、ユーザーの実際のプレイ時間の計測に役立てます。

## 共通リファレンスドキュメント

プラットフォームごとの機能に加えて、SDK Game は Android と iOS の両方に適用できるリファレンスドキュメント一式を提供します。

* 各プラットフォームの統合ドキュメントと、関連する利用規約・ポリシーへのリンク
* SDK で使用される API/IAP ドキュメント：ドメイン、パス、パラメータおよび目的
* 各トラッキングイベントのフローを説明するドキュメント、および広告最適化に使用する MKT イベントに関する注記
