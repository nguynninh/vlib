現在 Vlive に送信されているイベントはパラメータが無いか、[Hub Logs Collection](https://vtvlivevn.sg.larksuite.com/docx/Dni9d8xqNo6wEjxVNMQuWBk7sFf) のドキュメントに比べて少ない状態です。
まだ適用されていない新しいイベントを補完し、統一する必要があります。

Vlive トラッキング game sdk へイベント送信時のデフォルトパラメータ：

`deviceId`: デバイス識別 ID

`deviceModel`: デバイスモデル名

`deviceBrand`: デバイスブランド

`deviceFullInfoJson`: JSON 形式のデバイス詳細情報

`deviceOs`: デバイスの OS 名（例：Android, iOS）

`deviceOsVersion`: デバイスの OS バージョン

`appClientId`: アプリのクライアント ID

`appId`: アプリ ID

`appName`: アプリ名

`appCode`: アプリコード

`appPackage`: アプリのパッケージ名（例：`com.example.app`）

`appVersion`: アプリのバージョン

`appSdkVersion`: アプリの SDK バージョン

`deviceFullInfoJson` には以下のパラメータが含まれます：

`width`: 画面の横幅（px）

`height`: 画面の縦幅（px）

`density_dpi`: 画面のピクセル密度（DPI）

`density`: 画面のスケール比率（例：2.0, 3.0）

`serial`: デバイスのシリアル番号

`model`: デバイスモデル名（例：Pixel 8, SM-A525F）

`id`: OS ビルド ID

`manufacture`: デバイス製造元（Samsung, Xiaomi, Oppo など）

`brand`: デバイスブランド

`type`: OS ビルドタイプ（`user`, `userdebug`, `eng`）

`user`: OS ビルドに使用されたユーザー名

`base`: 最初の Android プラットフォームバージョンコード（通常は 1）

`incremental`: OS のインクリメンタルビルドコード

`sdk`: Android API レベル（例：34）

`board`: デバイスのボード/ハードウェア名

`host`: OS ビルドに使用されたホスト名

`fingerprint`: デバイス/ROM ビルドの一意な識別文字列

`version_code`: ユーザーに表示される Android バージョン（例：14）
