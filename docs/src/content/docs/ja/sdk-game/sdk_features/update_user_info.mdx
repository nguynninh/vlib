## 課題提起

G1 電子ゲームサービスを利用したアカウント作成時、会社の各ゲームがプレイヤーの個人情報に関する規定を遵守できるようにするため、TT VplayHN1 は SDK と ID ページに以下の機能を追加することを提案します。

1. **顧客が提供する個人情報項目：**

この部分は既に実装済みですが、TT は顧客が情報更新をしやすいように、ID ページの「セキュリティ」タブと「アカウント」タブを一つに統合することを提案します。

| STT | 情報項目 | 必須/任意 |
| --- | --- | --- |
| 1 | 氏名 | 必須 |
| 2 | 生年月日 | 必須 |
| 3 | 身分証明書/国民 ID/パスポート番号 | 必須 |
| 4 | 発行日、発行場所 | 必須 |
| 5 | 常居所の登録住所 | 必須 |
| 6 | 電話番号 | 任意 |
| 7 | メールアドレス | 任意 |

2. **個人情報が未入力のアカウントに対する SDK ログインブロックポップアップ**

顧客が SDK にログインする際、アカウントが必須の個人情報項目（上記で\*印が付いているもの）を入力していない場合、警告ポップアップが表示されます。この警告ポップアップは、サービスごとの SDK に対して CMS から ON/OFF を切り替えられる3段階のレベルがあります。

- レベル1：ポップアップを表示しない（アカウントが情報を更新済みかどうかのチェックをスキップし、直接ゲームに入る）。

- レベル2：ポップアップを閉じることを許可する（ログインのたびにポップアップを表示し、顧客はポップアップを閉じてゲームを続けられる）。

- レベル3：ポップアップを閉じることを許可しない（ログインのたびに表示し、アカウントは必ず [id.vplay.vn](http://id.vplay.vn/) または [id.onlive.vn](http://id.onlive.vn/) のウェブサイトで情報を更新しなければならない）。


| STT | 表示条件 | 内容 |
| --- | --- | --- |
| 1 | アカウントが必須情報を更新していない | タイトル：情報の更新 [エラーコード]<br/>内容：あなたのアカウントは規定に基づく個人情報の更新が完了していません。ホームページにアクセスして手続きを行うか、ホットラインにご連絡ください。 |
| 2 | アカウントは情報を更新済みだが、生年月日に基づき18歳未満である | タイトル：情報の更新 [エラーコード]<br/>内容：あなたの年齢はこのゲームのコンテンツに適していません。詳細はホームページをご確認いただくか、ホットラインにご連絡ください。 |

3. **ID ページおよびチャージページにおける情報更新ガイドポップアップ**

顧客が ID ページにログインする際、アカウントが必須の個人情報項目を更新していない場合、顧客に情報更新を案内するガイドポップアップが表示されます。このガイドポップアップは、CMS から ON/OFF を切り替えられる3段階のレベルがあります。

- レベル1：ポップアップを表示しない

- レベル2：ガイドポップアップを表示するが、スキップ可能

- レベル3：ガイドポップアップを表示し、個人情報を更新しない限り取引操作を行えない
