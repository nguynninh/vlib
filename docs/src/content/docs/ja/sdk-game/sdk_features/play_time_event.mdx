## 要件

1. ログイン成功後、30秒、1分、3分、5分、15分、30分、1時間、以降は1時間間隔で定期的に発火する。

2. キャラクター作成が成功した場合、play time を 0 にリセットし、(1) に従って再計算する。

3. ユーザーが日をまたいでプレイした場合、UTC+7 の 0:00 に自動的に play time を 0 にリセットし、(1) に従って再計算する。

4. ユーザーがホーム画面に戻った場合 -> play_time を pause -> ログアウトされずにゲームに戻った場合 -> pause した時点から playtime のカウントを継続する。

5. ホーム画面に戻った後、再度ゲームに入った際にユーザーがログアウトされていた場合は、(1) からカウントし直す。
