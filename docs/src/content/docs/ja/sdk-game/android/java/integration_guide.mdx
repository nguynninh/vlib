このページでは、サンプルプロジェクト `Integration Sdk Game Example` の構成に沿って、実際の Android（Java）プロジェクトへ SDK を素早く統合する方法を説明します。SDK の全機能（多言語対応、詳細なトラッキング、フローティングボタンなど）については、[開発者向けガイド](/sdk-game/android/java/guides) を参照してください。設定情報（client_id、client_secret、内部キーなど）の取得方法については、[設定ガイド](/sdk-game/android/java/dev_config) を参照してください。

## 1. 必要なファイル一覧

統合を始める前に、以下のファイル（VTVLive チームより提供）をすべて準備してください。

1. `res` フォルダ（アイコン、SDK 設定用リソース）
2. `strings.xml`
3. `keysdk.txt` — 内部 Maven から SDK ライブラリを取得するための専用アクセストークンを含む
4. `icon app` フォルダ
5. `keystore` フォルダ（`.jks` ファイルおよびアプリ署名情報）
6. `google-services.json`
7. サンプルデモプロジェクト（`Integration Sdk Game Example`）

:::caution
`keysdk.txt` と `keystore` フォルダには機密情報（アクセストークン、keystore のパスワード）が含まれています。これらのファイルは絶対にパブリックリポジトリへコミットせず、広く共有される資料に直接貼り付けないでください。
:::

## 2. Gradle の設定

### 2.1. `settings.gradle` — 内部 Maven リポジトリの宣言

```groovy
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }
        maven {
            url "https://source.vtvlive.vn/api/v4/projects/2352/packages/maven"
            credentials(HttpHeaderCredentials) {
                name = "Private-Token"
                value = "<PRIVATE_TOKEN_1>" // 実際の値は keysdk.txt から取得する
            }
            authentication {
                header(HttpHeaderAuthentication)
            }
        }
        maven {
            url 'https://source.vtvlive.vn/api/v4/projects/2558/packages/maven'
            credentials(HttpHeaderCredentials) {
                name = "Private-Token"
                value = "<PRIVATE_TOKEN_2>" // 実際の値は keysdk.txt から取得する
            }
            authentication {
                header(HttpHeaderAuthentication)
            }
        }
    }
}
```

:::danger[ドキュメントに実際のトークンを使用しないこと]
上記 2 つの `Private-Token` の値は、VTVLive が各パートナーに個別に提供する `keysdk.txt` ファイルから取得してください。他のパートナーのトークンをコピーしたり、公開ソースコード内にトークンを漏らしたりしては **いけません**。
:::

:::note
上記の例はサンプルプロジェクト（SDK バージョン `1.3.8`）からそのまま引用したものです。リリース前に、[開発者向けガイド](/sdk-game/android/java/guides#cài-đặt-sdk) で最新の安定版バージョンを再確認してください。
:::

### 2.4. 設定ファイルをプロジェクトに追加

1. `res.zip` を解凍し、プロジェクトの `res` フォルダにコピー＆上書きします（`xml/vtvlive_config_sdk_game_defaults.xml` および各種 `drawable-*` フォルダを含む）。
2. 提供された `strings.xml` にある Facebook 関連のパラメータ（`facebook_app_id`、`fb_login_protocol_scheme`、`facebook_client_token`）を、ご自身のプロジェクトの `strings.xml` にコピーします。
3. `google-services.json` を `app` モジュールのルートフォルダにコピーします。

## 3. `AndroidManifest.xml` の宣言

メインの Activity は通常のランチャー Activity として宣言するだけで構いません。この段階で SDK が追加のパーミッションや特別なコンポーネントを要求することはありません。

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:supportsRtl="true"
        android:theme="@style/AppTheme">
        <activity
            android:name=".MainActivity"
            android:configChanges="keyboard|keyboardHidden|screenLayout|screenSize|orientation|locale|layoutDirection"
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>
    </application>
</manifest>
```

:::note
画面回転時に Activity が再起動されないようにするため、`android:configChanges` 属性には上記の値（特に `orientation`、`screenSize`）をすべて含める必要があります。フローティングボタンの UI の回転処理は、SDK が `resetFloatingButton()` を通じて別途処理します（[5 項](#5-xử-lý-khi-xoay-màn-hình)を参照）。
:::

## 4. SDK の初期化とログイン

以下はサンプルプロジェクトの `MainActivity.java` からそのまま抜粋した、統合に必要な最小限のコード一式です。

```java
package vn.vplay.ngaothevolam.t035a;

import android.app.Activity;
import android.content.res.Configuration;
import android.os.Bundle;
import android.util.Log;
import android.view.Window;
import android.view.WindowManager;
import android.widget.Button;

import org.jetbrains.annotations.NotNull;

import vlive.sdk.game.VLiveSdkGame;
import vlive.sdk.game.callback.AuthenticationListener;
import vlive.sdk.game.callback.PaymentListener;
import vlive.sdk.game.enumext.EnvironmentSdk;
import vlive.sdk.game.model.UserInfo;

public class MainActivity extends Activity implements AuthenticationListener, PaymentListener {

    private Button btnLogin;
    private Button btnLogout;
    private Button btnPayment;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        requestWindowFeature(Window.FEATURE_NO_TITLE);
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        getWindow().setFlags(WindowManager.LayoutParams.FLAG_FULLSCREEN, WindowManager.LayoutParams.FLAG_FULLSCREEN);

        btnLogin = findViewById(R.id.btnLogin);
        btnLogout = findViewById(R.id.btnDashboard);
        btnPayment = findViewById(R.id.btnListProduct);
        bindOnClickListener();

        // SDK の初期化
        VLiveSdkGame vLiveSdkGame = VLiveSdkGame.getInstance();
        vLiveSdkGame.setEnvironment(EnvironmentSdk.Production); // テスト時は .Development に変更する
        vLiveSdkGame.setActivity(this);
        vLiveSdkGame.setAuthenticationListener(this);
        vLiveSdkGame.setPaymentListener(this);

        // SDK の初期化が完了したら自動的にログインする
        vLiveSdkGame.setInitStatusListener(isCreated -> {
            if (isCreated) {
                VLiveSdkGame.getInstance().login();
            }
        });
    }

    private void bindOnClickListener() {
        btnLogin.setOnClickListener(v -> VLiveSdkGame.getInstance().login());
        btnLogout.setOnClickListener(v -> VLiveSdkGame.getInstance().logout());
        btnPayment.setOnClickListener(v -> {
            String productId = "vn.vplay.ngaothevolam.t035a.79";
            String characterId = "324132321";
            String serverId = "123";
            VLiveSdkGame.getInstance().payProduct(productId, characterId, serverId);
        });
    }

    @Override
    public void onLoginSuccessful(UserInfo userInfo, String accessToken, String refreshToken, String idToken) {
        Log.i("TAG GAME", "userInfoId: " + userInfo.getUserId());
        Log.i("TAG GAME", "userInfoName: " + userInfo.getUserName());
    }

    @Override
    public void onLogoutSuccessful() {
        Log.i("TAG GAME", "LogOut");
    }

    @Override
    public void onPayProductSuccess(String orderId, String productId) {
        Log.i("TAG GAME", "Payment " + orderId + " " + productId);
    }

    @Override
    public void onPayProductError(String error) {
        Log.i("TAG GAME", "Payment error: " + error);
    }
}
```

初期化の各ステップの意味は以下のとおりです。

- `setEnvironment(...)` — `Production` または `Development` の環境を選択します。
- `setActivity(this)` — SDK が UI（ログイン、フローティングボタンなど）を表示するために使用する Activity を指定します。
- `setAuthenticationListener(this)` / `setPaymentListener(this)` — コールバックを受け取るため、Activity は `AuthenticationListener` と `PaymentListener` を実装する必要があります。
- `setInitStatusListener(...)` — SDK の初期化が完了したかどうかを知らせるコールバック。`onCreate` 内で直接 `login()` を呼ぶのではなく、このコールバック内で呼び出すことを推奨します。

## 5. 画面回転時の処理

```java
@Override
public void onConfigurationChanged(@NotNull Configuration newConfig) {
    super.onConfigurationChanged(newConfig);
    VLiveSdkGame.getInstance().resetFloatingButton();
}
```

## 6. 次のステップ

上記の初期化 → ログイン → 決済のフローが動作したら、続けて以下に沿って統合を完成させてください。

- [開発者向けガイド](/sdk-game/android/java/guides) — 必須のイベントトラッキング（patch、extract、character、map user など）、多言語対応、フローティングボタン、ProGuard、ビルド前のバージョン確認。
- [設定ガイド](/sdk-game/android/java/dev_config) — `client_id`、`client_secret` の取得、および Hub/Firebase Remote Config の設定。
- [SDK 統合時の確認フロー](/sdk-game/android/java/integrate) — APK/AAB を VTVLive の審査に提出する前のチェックリスト。
