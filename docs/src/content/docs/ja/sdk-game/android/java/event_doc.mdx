## 2. Vlive Tracking（Hub Logs Collection）への送信イベント

現在、Vliveに送信されているイベントはパラメータがない、またはHub Logs Collectionドキュメントに基づくパラメータが少ない状態です。まだ適用されていない新しいイベントは追加・統一が必要です。

### sdk vlive tracking gameへのイベント送信時のデフォルトパラメータ

- `deviceId` : 端末識別ID
- `deviceModel` : 端末モデル名
- `deviceBrand` : 端末ブランド
- `deviceFullInfoJson` : JSON形式の端末の詳細情報
- `deviceOs` : 端末OS名（例: Android, iOS）
- `deviceOsVersion` : 端末OSバージョン
- `appClientId` : アプリケーションのclient ID
- `appId` : アプリケーションID
- `appName` : アプリケーション名
- `appCode` : アプリケーションコード
- `appPackage` : アプリケーションのpackage名（例: `com.example.app`）
- `appVersion` : アプリケーションバージョン
- `appSdkVersion` : アプリケーションのSDKバージョン

`deviceFullInfoJson` には以下のパラメータが含まれます:

- `width` : 画面の横幅（px）
- `height` : 画面の縦幅（px）
- `density_dpi` : 画面のピクセル密度（DPI）
- `density` : 画面のスケール比率（例: 2.0, 3.0）
- `serial` : 端末のシリアル番号
- `model` : 端末のモデル名（例: Pixel 8, SM-A525F）
- `id` : OSのビルドID
- `manufacture` : 端末の製造元（Samsung, Xiaomi, Oppoなど）
- `brand` : 端末のブランド
- `type` : OSビルドの種類（`user`, `userdebug`, `eng`）
- `user` : OSビルドに使用されたユーザー名
- `base` : Androidプラットフォームの最初のバージョンコード（通常1）
- `incremental` : OSの増分ビルドコード
- `sdk` : Android APIレベル（例: 34）
- `board` : 端末のボード/ハードウェア名
- `host` : OSビルドに使用されたホスト名
- `fingerprint` : 端末/ROMを一意に識別する文字列
- `version_code` : ユーザーに表示されるAndroidバージョン（例: 14）
