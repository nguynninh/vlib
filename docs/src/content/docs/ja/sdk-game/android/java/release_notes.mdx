このページでは、VTV Live Android Game SDK のリリース履歴を一覧で示します。

表の各列の意味は以下のとおりです。

- **バージョン**: リリースされたバージョンの識別名。
- **ファイル**: 該当バージョンの `.aar`/Maven アーティファクトのダウンロードリンク。
- **コミットID**: このビルドに対応するソースコード管理システム上のコミットID。
- **リリース日**: このバージョンがリリースされた日時。
- **変更内容**: 前バージョンからの主な変更点の要約。

:::note
このページはまだ作成されたばかりで、これまでにリリースされた全バージョンの履歴が揃っていません。特定のバージョンの情報が必要な場合は、VTVLive チームまでお問い合わせください。
:::
