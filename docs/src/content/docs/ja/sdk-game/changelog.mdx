## 1.0.2

### 追加

- 実際の SDK サンプルプロジェクトを基に、Android(Java)の**統合ガイド**と**リリースノート**ページを新規追加。
- iOS の **Swift 統合ガイド**を実際の Swift API(`Sdk`、`SdkDelegate`、`SdkTracking`)に基づいて全面的に書き直し。以前 Objective-C ページから誤ってコピーされていた内容を置き換え。

### 更新

- iOS Objective-C の**統合ガイド**、**リリースノート**、および SDK 更新ページ(5.0.0、5.1.4、5.3.1)をより分かりやすく書き直し。元の資料にあった誤りや不足を修正し、要確認箇所を明示。
- サイドバーを自動生成ではなく明示的な並び順に変更し、4 言語(vi/en/zh/ja)すべてのサイドバー項目に翻訳を追加。
- 上記すべての内容を英語・中国語・日本語に同期。

### 削除

- 4 言語すべてで使われなくなった旧 SDK Game ドキュメントページ(`sdk_features/*`、`tai_lieu_*`)を削除。

## 1.0.0

### 追加

- Android と iOS 向けの SDK Game ドキュメントを追加。概要、統合ドキュメント、API ドキュメント、イベントフロードキュメント、SDK 機能を含みます。
- Android と iOS 向けの Game v2 OIDC 統合ドキュメントを追加。
- バージョンごとの更新内容を記録する **Changelog** タブを追加。

### 更新

- SDK Game ドキュメントの構成を **Overview**、**Integration Documentation**、**API Documentation**、**Event Workflow**、**SDK Features**、**Android**、**iOS** に整理。
- ドキュメントバージョン `1.0.0` の初期内容を追加。
