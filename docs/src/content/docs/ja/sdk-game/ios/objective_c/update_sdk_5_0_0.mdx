---

## 1. 変更概要

- デプロイメントターゲットを iOS 15 に引き上げ。
- Firebase を 12.0.0 にアップデート。
- AppsFlyerFramework を 6.17.2 にアップデート。
- トラッキングロジックをアップデート。
- FirebaseCrashlytics 12.0.0 を追加。

## 2. Podfile のアップデート

`Podfile` を以下のように修正し、`pod install` を再実行してください。

```ruby
platform :ios, '15.0'
target 'SdkExample' do
  use_frameworks!
  pod 'GoogleSignIn', '7.1.0'
  pod 'Firebase', '12.0.0'
  pod 'FirebaseMessaging', '12.0.0'
  pod 'FirebaseRemoteConfig', '12.0.0'
  pod 'AppsFlyerFramework', '6.17.7'
  pod 'JWT', '2.2.0'
  pod 'TikTokBusinessSDK', '1.5.0'
  pod 'FirebaseRemoteConfig', '12.0.0'
end
target 'FirebaseNotificationServiceExtension' do
 use_frameworks!
 pod 'Firebase', '12.0.0'
 pod 'FirebaseMessaging', '12.0.0'

end
post_install do |lib|
    lib.pods_project.targets.each do |target|
        if target.name == 'GoogleSignIn' || target.name == 'Firebase' || target.name == 'FirebaseRemoteConfig' || target.name == 'FirebaseMessaging' || target.name == 'AppsFlyerFramework' ||  target.name == 'JWT' ||  target.name == 'TikTokBusinessSDK'
            target.build_configurations.each do |config|
                config.build_settings['BUILD_LIBRARY_FOR_DISTRIBUTION'] = 'YES'
            end
        end
        
        target.build_configurations.each do |config|
            config.build_settings['IPHONEOS_DEPLOYMENT_TARGET'] = '15.0'
        end
    end
end
```

## 3. Xcode でのライブラリ再設定

`pod install` が完了したら、`.xcworkspace` ファイルでプロジェクトを開き直し、下図のように各ライブラリの **Embed & Sign** / **Do Not Embed** 設定を確認してください（詳しい設定方法は[統合ガイド](/sdk-game/ios/objective_c/integration_guide)を参照）。

## 4. AppDelegate のアップデート

新しい SDK バージョンに合わせて、`AppDelegate.m` を以下のテンプレートのようにアップデートしてください。

```Objective-C
@import Firebase;

- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    [[Sdk sharedInstance] initWithDelegate:self application:application launchOptions:launchOptions isProdEnv:TRUE];
    [[Sdk sharedInstance] setLocationFloatingButton:20 with:100];
    [[Sdk sharedInstance] setGrantEnv:NO];
    return YES;
}

-(void) getLangaugeSdk: (NSString *) langauge {
    // SDK の言語が変更されたときの処理
}

- (void)application:(UIApplication *)application didRegisterForRemoteNotificationsWithDeviceToken:(NSData *)deviceToken {
    [FIRMessaging messaging].APNSToken = deviceToken;
}

- (void)messaging:(FIRMessaging *)messaging didReceiveRegistrationToken:(NSString *)fcmToken {
}
```

## 5. キャラクター作成ログ関数のアップデート

このバージョンから、`logStartedCharacterCreation` または `logFinishedCharacterCreation` を呼び出す際に、以下のパラメータを追加で渡す必要があります。

- `logStartedCharacterCreation`: `serverId` と `serverName` を追加。
- `logFinishedCharacterCreation`: `characterId` と `characterName` を追加。

```Objective-C
-(void) logStartedCharacterCreation:(NSString *) serverId withSeverName: (NSString *) serverName;
-(void) logFinishedCharacterCreation:(NSString *) characterId characterName :(NSString*)characterName;
```

## 6. Firebase Crashlytics 用 dSYM のアップロード

`.ipa` ファイルのビルドが完了したら、**Show in Finder** を選択して dSYM ファイルを取得し、`.ipa` ファイルとあわせて VTVLive チームに送付してください。
