このページでは、iOS版iTapSDKのリリース履歴を、**SDKライン**（Game SDK、OIDC v2、ON Live、SeeNow）ごとに分けて記載しています。各SDKラインはそれぞれ独立してバージョンが増加していきます — 統合しているSDKラインに対応する表を選んでください。

表の各列の意味:

- **バージョン**: リリースの識別名。
- **ファイル**: 該当バージョンの`.xcframework`ファイル（または設定ファイル）のダウンロードリンク。
- **コミットID**: このビルドに対応するソースコード管理システム上のコミットID。
- **MD5**: ダウンロードしたファイルが破損・改変されていないかを確認するためのチェックサム。
- **リリース日**: このバージョンがリリースされた日時。
- **変更内容**: 前バージョンからの主な変更点の要約。

:::note
リリース時点で開発チームが情報（コミットID、MD5、リリース日など）を完全に更新していないため、一部のセルは空欄になっています。不足している情報が必要な場合は、VTVLiveチームまでお問い合わせください。
:::
