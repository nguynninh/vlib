## Purpose

## Requirements

1. After a successful login, fire periodically at 30s, 1m, 3m, 5m, 15m, 30m, 1 hour, and every 1 hour thereafter.

2. If a character is created successfully, reset play time = 0 and recalculate according to (1).

3. If the user keeps playing past midnight, play time will automatically reset to 0 at 0:00 UTC+7 and recalculate according to (1).

4. If the user returns to the home screen -> play_time is paused -> the user returns to the game without being logged out -> playtime counting resumes from the point it was paused.

5. If the user returns to home and then re-enters the game after being logged out, counting restarts from (1).
