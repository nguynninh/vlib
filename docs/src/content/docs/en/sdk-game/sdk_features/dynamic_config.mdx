---
title: Dynamic configuration from BE API and Firebase Remote Config
description: Mechanism for fetching dynamic configuration for the SDK via the BE API with fallback to Firebase Remote Config, enabling customization of domain and configuration without rebuilding the application.
---

## Overview

1. Purpose

    1. Minimize configuration errors when integrating with partners

    2. Allow customizing the domain and configuration in emergency cases, avoiding the need to rebuild the SDK -> re-review the application.

2. Additional information

    The SDK will prioritize fetching configuration from the BE API. If the API call fails or the returned data cannot be decoded, the SDK will automatically fall back to Firebase Remote Config. If both sources fail, the SDK will use the configuration previously saved in SharedPreferences (or the default configuration in the Firebase XML file if it is the first installation).

## API

1. Flow diagram

    - Android

```mermaid
%% width: 1100
flowchart LR
    Start((Startup)) --> FirstInstall{First<br/>Install}
    FirstInstall -- true --> SaveDefault[Save default<br/>configuration from<br/>Firebase XML file<br/>to SharedPreferences]
    SaveDefault --> RemoteApi[Remote Config API]
    FirstInstall -- false --> RemoteApi

    RemoteApi --> ApiState{Api<br/>State}
    ApiState -- "Success" --> DecodeApi{Decode}
    ApiState -- "failure" --> DecodeApi

    DecodeApi -- "failure" --> FirebaseRemote[Firebase Remote<br/>Config]
    ApiState -- "failure" --> FirebaseRemote
    FirebaseRemote --> FirebaseState{Firebase<br/>State}
    FirebaseState -- "success" --> DecodeFirebase{Decode}
    FirebaseState -- "failure" --> InitAppInfo[Initialize AppInfo from<br/>SharedPreferences]

    DecodeFirebase -- "success" --> SaveConfig[Save configuration to<br/>SharedPreferences]
    DecodeApi -- "success" --> SaveConfig

    SaveConfig --> CheckDomain{Check if Domain Id<br/>has changed}
    CheckDomain -- true --> Logout[Logout]

    SaveConfig --> InitAppInfo
    InitAppInfo --> Done((Done))
```

    - iOS

```mermaid
%% width: 1100
flowchart LR
    Start((app startup)) --> A[Call API to fetch dynamic config]
    A --> B{API response status}
    B -->|true| C{check data}
    B -->|false| D[fetch config from firebase config]
    D --> E{response status from firebase}
    E -->|true| C
    E -->|false| F[fetch default data from app config]
    C -->|false| F
    C -->|true| G{compare with userDefault data}
    F --> G
    G -->|userDefault # nil| H{compare domain}
    G -->|userDefault nil| K[Save to userDefault]
    H -->|different| I[logout]
    H -->|same| K
    I --> K
    K --> End((end))
```
