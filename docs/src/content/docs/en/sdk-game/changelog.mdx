## 1.1.0

### Added

- New interactive, step-by-step **Integration Guide** for Android (Java), replacing the previous static Markdown page.
- Deep links to individual steps of the guide via the sidebar and the page's pagination.

### Updated

- Synced the interactive guide's light/dark appearance with the site's real theme toggle, covering all content, code blocks, the Logcat console, and the media lightbox.
- Expanded the Android > Java sidebar with every step of the Integration Guide.
- Synced all of the above content into English, Chinese, and Japanese.

### Removed

- The interactive guide's internal navigation panel, progress bar, and its own next/previous footer, now that they duplicate the site's real sidebar and pagination.
- The guide's standalone language dropdown; the guide's language now follows the site's own locale route.

## 1.0.2

### Added

- New **Integration Guide** and **Release Notes** pages for Android (Java), written from a real SDK sample project.
- Fully rewrote the iOS **Swift Integration Guide** using the real Swift API (`Sdk`, `SdkDelegate`, `SdkTracking`), replacing content that had previously been copied from the Objective-C page by mistake.

### Updated

- Rewrote the **Integration Guide**, **Release Notes**, and SDK update pages (5.0.0, 5.1.4, 5.3.1) for iOS Objective-C to be clearer and easier to follow; fixed errors/gaps in the original source and clearly flagged sections that still need verification.
- Reorganized the sidebar with explicit ordering instead of autogeneration, and added translations for every sidebar entry across all 4 locales (vi/en/zh/ja).
- Synced all of the above content into English, Chinese, and Japanese.

### Removed

- Removed outdated SDK Game documentation pages (`sdk_features/*`, `tai_lieu_*`) across all 4 locales.

## 1.0.0

### Added

- SDK Game documentation for Android and iOS, including overview, integration documentation, API documentation, event workflow documentation, and SDK features.
- Game v2 OIDC integration documentation for Android and iOS.
- A **Changelog** tab for tracking documentation updates by version.

### Updated

- Standardized the SDK Game documentation structure into **Overview**, **Integration Documentation**, **API Documentation**, **Event Workflow**, **SDK Features**, **Android**, and **iOS**.
- Added the foundation content for documentation version `1.0.0`.
