This page lists the release history of the iTapSDK on iOS, organized by each separate **SDK line** (Game SDK, OIDC v2, ON Live, SeeNow). Each SDK line has its own independently incrementing version — make sure you pick the table that matches the SDK line you are integrating.

Meaning of the table columns:

- **Version**: the identifier name of the release.
- **File**: download link for the `.xcframework` (or configuration file) of that version.
- **Commit hash**: the commit hash in the corresponding source control system for this build.
- **MD5**: the integrity checksum of the file, used to verify the downloaded file is not corrupted or altered.
- **Release date**: when this version was released.
- **Changes**: summary of the main changes compared to the previous version.

:::note
Some cells are left blank because the development team had not fully updated the information (commit hash, MD5, release date...) at the time of release. If you need missing information, please contact the VTVLive team.
:::
