This page walks you through a quick integration of the SDK into a real Android (Java) project, following the exact structure of the `Integration Sdk Game Example` sample project. For the full set of SDK features (multi-language, detailed tracking, floating button...), see the [Developer Guide](/sdk-game/android/java/guides). To get configuration information (client_id, client_secret, internal keys...), see the [Configuration Guide](/sdk-game/android/java/dev_config).

## 1. Required files

Before integrating, you need to prepare all of the following files (provided by the VTVLive team):

1. `res` folder (icons, SDK configuration resources)
2. `strings.xml`
3. `keysdk.txt` — contains the private access token used to download the SDK library from the internal Maven repository
4. `icon app` folder
5. `keystore` folder (`.jks` file and app signing information)
6. `google-services.json`
7. Sample demo project (`Integration Sdk Game Example`)

:::caution
`keysdk.txt` and the `keystore` folder contain confidential information (access token, keystore password) — never commit these files to a public repository, and never paste them directly into widely shared documentation.
:::

## 2. Gradle configuration

### 2.1. `settings.gradle` — declare the internal Maven repository

```groovy
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }
        maven {
            url "https://source.vtvlive.vn/api/v4/projects/2352/packages/maven"
            credentials(HttpHeaderCredentials) {
                name = "Private-Token"
                value = "<PRIVATE_TOKEN_1>" // get the real value from keysdk.txt
            }
            authentication {
                header(HttpHeaderAuthentication)
            }
        }
        maven {
            url 'https://source.vtvlive.vn/api/v4/projects/2558/packages/maven'
            credentials(HttpHeaderCredentials) {
                name = "Private-Token"
                value = "<PRIVATE_TOKEN_2>" // get the real value from keysdk.txt
            }
            authentication {
                header(HttpHeaderAuthentication)
            }
        }
    }
}
```

:::danger[Do not use real tokens in documentation]
The two `Private-Token` values above must come from the `keysdk.txt` file that VTVLive provides individually to each partner — **do not** copy another partner's token, and do not leak the token in public source code.
:::

```groovy
buildscript {
    repositories {
```

:::note
The example above is taken directly from the sample project (SDK version `1.3.8`). Before release, check the latest stable version in the [Developer Guide](/sdk-game/android/java/guides#cài-đặt-sdk).
:::

### 2.4. Add configuration files to the project

1. Unzip `res.zip`, then copy and overwrite the project's `res` folder (including `xml/vtvlive_config_sdk_game_defaults.xml` and the `drawable-*` folders).
2. Copy the Facebook parameters from the provided `strings.xml` into your project's `strings.xml` (`facebook_app_id`, `fb_login_protocol_scheme`, `facebook_client_token`).
3. Copy `google-services.json` into the root folder of the `app` module.

## 3. Declare `AndroidManifest.xml`

The main Activity only needs to be declared as a normal launcher Activity — the SDK does not require any special permission or component at this step:

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:supportsRtl="true"
        android:theme="@style/AppTheme">
        <activity
            android:name=".MainActivity"
            android:configChanges="keyboard|keyboardHidden|screenLayout|screenSize|orientation|locale|layoutDirection"
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>
    </application>
</manifest>
```

:::note
The `android:configChanges` attribute must include all the values above (especially `orientation` and `screenSize`) so the Activity is not restarted on screen rotation — the SDK handles rotating the floating button UI separately via `resetFloatingButton()` (see [section 5](#5-xử-lý-khi-xoay-màn-hình)).
:::

## 4. Initialize and log in to the SDK

This is the complete minimal integration code, taken directly from `MainActivity.java` in the sample project:

```java
package vn.vplay.ngaothevolam.t035a;

import android.app.Activity;
import android.content.res.Configuration;
import android.os.Bundle;
import android.util.Log;
import android.view.Window;
import android.view.WindowManager;
import android.widget.Button;

import org.jetbrains.annotations.NotNull;

import vlive.sdk.game.VLiveSdkGame;
import vlive.sdk.game.callback.AuthenticationListener;
import vlive.sdk.game.callback.PaymentListener;
import vlive.sdk.game.enumext.EnvironmentSdk;
import vlive.sdk.game.model.UserInfo;

public class MainActivity extends Activity implements AuthenticationListener, PaymentListener {

    private Button btnLogin;
    private Button btnLogout;
    private Button btnPayment;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        requestWindowFeature(Window.FEATURE_NO_TITLE);
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        getWindow().setFlags(WindowManager.LayoutParams.FLAG_FULLSCREEN, WindowManager.LayoutParams.FLAG_FULLSCREEN);

        btnLogin = findViewById(R.id.btnLogin);
        btnLogout = findViewById(R.id.btnDashboard);
        btnPayment = findViewById(R.id.btnListProduct);
        bindOnClickListener();

        // Initialize the SDK
        VLiveSdkGame vLiveSdkGame = VLiveSdkGame.getInstance();
        vLiveSdkGame.setEnvironment(EnvironmentSdk.Production); // switch to .Development for testing
        vLiveSdkGame.setActivity(this);
        vLiveSdkGame.setAuthenticationListener(this);
        vLiveSdkGame.setPaymentListener(this);

        // Automatically log in once the SDK finishes initializing
        vLiveSdkGame.setInitStatusListener(isCreated -> {
            if (isCreated) {
                VLiveSdkGame.getInstance().login();
            }
        });
    }

    private void bindOnClickListener() {
        btnLogin.setOnClickListener(v -> VLiveSdkGame.getInstance().login());
        btnLogout.setOnClickListener(v -> VLiveSdkGame.getInstance().logout());
        btnPayment.setOnClickListener(v -> {
            String productId = "vn.vplay.ngaothevolam.t035a.79";
            String characterId = "324132321";
            String serverId = "123";
            VLiveSdkGame.getInstance().payProduct(productId, characterId, serverId);
        });
    }

    @Override
    public void onLoginSuccessful(UserInfo userInfo, String accessToken, String refreshToken, String idToken) {
        Log.i("TAG GAME", "userInfoId: " + userInfo.getUserId());
        Log.i("TAG GAME", "userInfoName: " + userInfo.getUserName());
    }

    @Override
    public void onLogoutSuccessful() {
        Log.i("TAG GAME", "LogOut");
    }

    @Override
    public void onPayProductSuccess(String orderId, String productId) {
        Log.i("TAG GAME", "Payment " + orderId + " " + productId);
    }

    @Override
    public void onPayProductError(String error) {
        Log.i("TAG GAME", "Payment error: " + error);
    }
}
```

What the initialization steps do:

- `setEnvironment(...)` — choose the `Production` or `Development` environment.
- `setActivity(this)` — the Activity the SDK uses to display UI (login, floating button...).
- `setAuthenticationListener(this)` / `setPaymentListener(this)` — the Activity must implement `AuthenticationListener` and `PaymentListener` to receive callbacks.
- `setInitStatusListener(...)` — callback that reports whether the SDK has finished initializing; you should call `login()` inside this callback instead of calling it directly in `onCreate`.

## 5. Handling screen rotation

```java
@Override
public void onConfigurationChanged(@NotNull Configuration newConfig) {
    super.onConfigurationChanged(newConfig);
    VLiveSdkGame.getInstance().resetFloatingButton();
}
```
