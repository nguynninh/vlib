## 2. Events sent to Vlive Tracking (Hub Logs Collection)

Currently, events sent to Vlive have no parameters or only a few parameters compared to the Hub Logs Collection documentation. New events that have not yet been applied need to be added and unified.

### Default parameters sent with events to the SDK Vlive game tracking

- `deviceId`: Device identifier ID
- `deviceModel`: Device model name
- `deviceBrand`: Device brand
- `deviceFullInfoJson`: Full device information as JSON
- `deviceOs`: Device OS name (e.g.: Android, iOS)
- `deviceOsVersion`: Device OS version
- `appClientId`: Application client ID
- `appId`: Application ID
- `appName`: Application name
- `appCode`: Application code
- `appPackage`: Application package name (e.g.: `com.example.app`)
- `appVersion`: Application version
- `appSdkVersion`: Application SDK version

`deviceFullInfoJson` includes the following parameters:

- `width`: Screen width (px)
- `height`: Screen height (px)
- `density_dpi`: Screen pixel density (DPI)
- `density`: Screen scale ratio (e.g.: 2.0, 3.0)
- `serial`: Device serial number
- `model`: Device model name (e.g.: Pixel 8, SM-A525F)
- `id`: OS build ID
- `manufacture`: Device manufacturer (Samsung, Xiaomi, Oppo...)
- `brand`: Device brand
- `type`: OS build type (`user`, `userdebug`, `eng`)
- `user`: Username used to build the OS
- `base`: First Android platform version code (usually 1)
- `incremental`: Incremental OS build code
- `sdk`: Android API Level (e.g.: 34)
- `board`: Device board/hardware name
- `host`: Hostname used to build the OS
- `fingerprint`: Unique identifier string for the device/ROM build
- `version_code`: Android version shown to the user (e.g.: 14)
