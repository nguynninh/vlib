This page lists the release history of the VTV Live Android Game SDK.

Meaning of the table columns:

- **Version**: the identifier name of the release.
- **File**: download link for the `.aar`/Maven artifact of that version.
- **Commit hash**: the commit hash in the corresponding source control system for this build.
- **Release date**: when this version was released.
- **Changes**: summary of the main changes compared to the previous version.

:::note
This page has just been created and does not yet have the full history of previously released versions. If you need information about a specific version, please contact the VTVLive team.
:::
