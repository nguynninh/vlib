1. Startup and configuration

```mermaid
flowchart LR
    A(("Startup")) --> B["Startup status<br/>Loading"]
    A --> C["Initialize<br/>KeyGenerator<br/>Set Activity<br/>SharedPreference<br/>Floating"]
    C --> D["Check initialization<br/>KeyGenerator<br/>ConfigRepository<br/>AppInfoFactory"]
    D --> E{"Configuration<br/>status"}
    D --> F["Configure Appinfo<br/>from system file"]
    E -- "Failed" --> H(("Startup status<br/>Error"))
    E -- "Success" --> G["Dynamic Appinfo<br/>configuration"]
    G --> I{"Check whether dynamic<br/>config from API<br/>is empty or null"}
    I -- "Failed" --> J{"Check whether Firebase<br/>config is empty or null"}
    J -- "Failed" --> K{"Check whether system<br/>config variable<br/>is empty or null"}
    K -- "Failed" --> H
    I -- "Success" --> L["Initialize other<br/>dependent classes<br/>Details"]
    J -.-> L
    K -.-> L
    L --> LOG[/"Detailed log"/]
    L --> M{"Check initialization"}
    M -- "Failed" --> H
    M -- "Success" --> N["Fetch game<br/>login configuration"]

    H --> S
```
