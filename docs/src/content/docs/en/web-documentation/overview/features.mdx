The Web Documentation platform offers a set of features designed to make writing, reading, and maintaining technical documentation easier.

## MDX content

Documentation is written in **MDX**, combining familiar Markdown syntax with the ability to embed components.

* Full support for Markdown syntax: headings, lists, tables, blockquotes...
* Allows embedding custom components (e.g. `<Tabs>`, `<TabItem>`) directly in the content.
* Each page has its own frontmatter (`title`, `description`) for SEO and navigation.

## Code blocks and line numbers

Code blocks are powered by Expressive Code, supporting:

* Syntax highlighting for many programming languages.
* Line numbers (`showLineNumbers`) when referencing a specific line.
* Titles for code blocks (`title="..."`) to describe the file or context.

## Mermaid diagrams

The platform integrates **Mermaid** to render diagrams directly from a code block, supporting:

* Flowcharts, sequence diagrams, class diagrams...
* ZenUML diagrams via the `@mermaid-js/mermaid-zenuml` plugin.
* Diagrams rendered directly on the page, without any external design tool.

## Callouts

The `:::note`, `:::tip`, `:::caution`, and `:::danger` syntax highlights important information without pulling the reader away from the main flow of the page.

## Enhanced tables

Markdown tables are extended with a `[width=...]` syntax (via a custom remark plugin) to control column width when needed.

## Full-text search

The entire documentation set is searchable by content, letting readers quickly jump to the page that contains a keyword instead of browsing through every section.

## Multiple languages

The platform supports several languages:

| Language   | Code |
| ---------- | ---- |
| Tiếng Việt | `vi` |
| English    | `en` |
| 中文        | `zh` |
| 日本語      | `ja` |

Each language has its own content directory, allowing translations to be maintained independently per locale.

## Light and dark theme

The interface automatically switches between light and dark themes based on the user's choice or system setting.

## Responsive layout

The interface is optimized to look good on desktop, tablet, and mobile, including wide tables and long code blocks.

## Navigation and Table of Contents

* An auto-generated sidebar (`autogenerate`) based on the documentation folder structure.
* A table of contents automatically built from the headings on a page, for quick jumps between sections.

## Version control via Git

Documentation is stored as MDX files in the repository, which enables:

* Tracking the history of content changes.
* Reviewing documentation changes the same way as code, through pull requests.
* Restoring or comparing previous versions when needed.
