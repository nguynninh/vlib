## 1.0.0

### Đã thêm

- Bộ tài liệu Interactive SDK cho Android và iOS, gồm hướng dẫn tích hợp, kiến trúc SDK, workflow chi tiết, API reference, tracking emit/ack và xử lý lỗi thường gặp.
- Tab **Nhật ký thay đổi** để ghi lại các cập nhật theo từng phiên bản tài liệu.

### Đã cập nhật

- Chuẩn hoá cấu trúc tài liệu Interactive theo nhóm **Bắt đầu**, **Android**, **iOS** và **Nhật ký thay đổi**.
- Bổ sung nội dung nền tảng cho bản tài liệu đầu tiên `1.0.0`.
