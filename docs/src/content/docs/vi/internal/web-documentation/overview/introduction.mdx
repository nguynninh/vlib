## Tổng quan

**Web Documentation** là một nền tảng tài liệu kỹ thuật dựa trên web, được thiết kế để cung cấp một kho kiến thức có cấu trúc, dễ tìm kiếm và dễ bảo trì.

Nền tảng sử dụng **MDX** làm định dạng nội dung chính, cho phép tài liệu kết hợp cú pháp Markdown thông thường với các component tương tác khi cần thiết.

Cách tiếp cận này giúp nội dung tài liệu vẫn đơn giản, dễ đọc, trong khi vẫn đủ linh hoạt để xây dựng những trang tài liệu kỹ thuật phức tạp hơn.

## Mục đích

Nền tảng Web Documentation được xây dựng nhằm:

* Tổ chức tài liệu kỹ thuật theo cấu trúc phân cấp rõ ràng.
* Lưu trữ tài liệu dưới dạng file MDX được quản lý phiên bản.
* Hỗ trợ cú pháp Markdown và các component MDX tuỳ biến.
* Cung cấp khả năng điều hướng nhanh giữa các trang tài liệu.
* Hỗ trợ ví dụ mã nguồn và sơ đồ kỹ thuật (Mermaid).
* Cung cấp tìm kiếm toàn văn (full-text search) trên toàn bộ tài liệu.
* Hỗ trợ giao diện sáng và tối.
* Hỗ trợ đa ngôn ngữ.
* Mang lại trải nghiệm responsive trên desktop, tablet và mobile.

## Cấu trúc tài liệu

Tài liệu được tổ chức thành nhiều khu vực chính:

```text
Web Documentation
│
├── Overview
├── Architecture
├── Development
├── Documentation
├── UI
├── Features
├── Deployment
├── Maintenance
└── Changelog
```

Mỗi phần tập trung vào một khía cạnh cụ thể của nền tảng, từ kiến trúc, phát triển cho đến triển khai và bảo trì.

## Định dạng nội dung

Các trang tài liệu được viết bằng **MDX**:

```mdx title="src/content/docs/vi/example.mdx"
---
title: "Giới thiệu"
description: "Giới thiệu về nền tảng Web Documentation."
---

## Giới thiệu

Đây là một trang tài liệu.

<CustomComponent />
```

MDX mang lại sự đơn giản của Markdown, đồng thời cho phép nhúng trực tiếp component vào trang tài liệu khi cần.

## Đối tượng sử dụng

Tài liệu này chủ yếu dành cho:

* Web developer làm việc trên nền tảng tài liệu.
* Developer đóng góp thêm trang tài liệu mới.
* Người bảo trì (maintainer) chịu trách nhiệm cho nền tảng.
* DevOps engineer phụ trách triển khai.
* Technical writer duy trì nội dung tài liệu.

## Nguyên tắc thiết kế

Nền tảng tuân theo một số nguyên tắc:

### Đơn giản

Tài liệu nên dễ viết, dễ đọc và dễ cập nhật.

### Có cấu trúc

Nội dung nên tuân theo một cấu trúc dễ đoán để người dùng nhanh chóng tìm thấy điều họ cần.

### Quản lý phiên bản

Tài liệu được lưu trữ cùng source code và quản lý qua Git.

### Có thể mở rộng

Component MDX cho phép hệ thống tài liệu hỗ trợ thêm các tính năng tương tác mà không cần thay đổi định dạng nội dung gốc.

### Dễ bảo trì

Cấu trúc project và quy ước viết tài liệu giúp các developer sau này dễ hiểu và duy trì hệ thống.
