## 1. Danh sách file cần thiết

Trước khi tích hợp, bạn cần chuẩn bị đầy đủ các file sau (do đội ngũ VTVLive cung cấp):

1. `AFNetworking.xcframework`
2. `iTapSdk.xcframework`
3. `ISdkTrackier.xcframework`
4. Google-Facebook `.plist`
5. `AppConfigDefault.plist`
6. Google-Facebook `.plist.txt`
7. Project demo mẫu (example)
8. File `.mobileprovision`

:::caution
Nếu bạn không nhận được đủ các file trên, hoặc có bất kỳ câu hỏi nào trong quá trình tích hợp, vui lòng liên hệ đội ngũ VTVLive để được hỗ trợ.
:::

Sau khi test xong ở môi trường dev, chúng tôi sẽ cung cấp key riêng cho môi trường production.

## 2. Các bước tích hợp SDK

Để tích hợp SDK, bạn hãy làm theo đúng thứ tự các bước dưới đây.

### 2.1. Thêm framework và library vào project

- Trong **project chính** (target app), chọn chế độ **Embed & Sign** cho các library đã liệt kê ở trên.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image1.png)

- Trong **UnityFramework** (nếu game build từ Unity), chọn chế độ **Do Not Embed** cho các library — vì các library này đã được embed ở target chính, tránh bị nhân đôi.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image2.png)

### 2.2. Thêm Notification Service Extension

Extension này giúp SDK xử lý và hiển thị đúng nội dung push notification (kể cả khi có ảnh, dữ liệu tuỳ biến từ Firebase).

1. Mở project iOS trong **Xcode**.
2. Vào **File > New > Target...**

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image3.png)

3. Trong danh sách template, tìm và chọn **Notification Service Extension**.
4. Bấm **Next**, đặt tên target — ví dụ `FirebaseNotificationServiceExtension` — rồi bấm **Finish**.
5. Khi Xcode hỏi có muốn kích hoạt scheme mới không, chọn **Activate**.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image4.png)

### 2.3. Thêm package dependencies

Thêm các package cần thiết (ví dụ Firebase) vào project qua **Swift Package Manager**:

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image5.png)

### 2.4. Cấu hình FirebaseNotificationServiceExtension

Mở file `NotificationService.swift` của extension và sửa nội dung như sau:

```swift
import UserNotifications
import Firebase
import FirebaseMessaging

class NotificationService: UNNotificationServiceExtension {

    var contentHandler: ((UNNotificationContent) -> Void)?
    var bestAttemptContent: UNMutableNotificationContent?

    override func didReceive(_ request: UNNotificationRequest, withContentHandler contentHandler: @escaping (UNNotificationContent) -> Void) {
        self.contentHandler = contentHandler
        bestAttemptContent = (request.content.mutableCopy() as? UNMutableNotificationContent)

        if let bestAttemptContent = bestAttemptContent {
            FIRMessaging.extensionHelper().populateNotificationContent(bestAttemptContent, withContentHandler: contentHandler)
        }
    }

    override func serviceExtensionTimeWillExpire() {
        if let contentHandler = contentHandler, let bestAttemptContent = bestAttemptContent {
            contentHandler(bestAttemptContent)
        }
    }
}
```

Sau bước này, cấu trúc project trên Xcode sẽ hiển thị như hình dưới:

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image6.png)

Ngoài ra:

- Để bật đăng nhập bằng Apple, bạn cần bật capability **Sign in with Apple** cho target chính.
- Để nhận được push notification, bạn cần thêm capability **Push Notifications**, đồng thời bật **Background Fetch** và **Remote Notifications** trong mục **Background Modes**.

## 3. Tích hợp các hàm SDK

SDK cung cấp một singleton `Sdk.sharedInstance` cho toàn bộ tính năng chính, và một singleton riêng `SdkTracking.shared` cho các hàm tracking sự kiện. Phần này hướng dẫn theo đúng vòng đời sử dụng: khởi tạo → đăng nhập → các thao tác trong game → đăng xuất.

### 3.1. Khởi tạo SDK

Trong `AppDelegate.swift`, import SDK, khai báo `AppDelegate` tuân thủ protocol `SdkDelegate`, và khởi tạo SDK ngay khi app khởi động:

```swift
import UIKit
import iTapSdk

@main
class AppDelegate: UIResponder, UIApplicationDelegate, SdkDelegate {

    func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
        Sdk.sharedInstance.initWithDelegate(self, application: application, launchOptions: launchOptions, environment: .prod)
        Sdk.sharedInstance.setLocationFloatingButton(width: 20, height: 100)
        return true
    }

    // Bắt buộc: chuyển tiếp URL callback cho Facebook / Google Sign-In
    func application(_ application: UIApplication, open url: URL, options: [UIApplication.OpenURLOptionsKey: Any] = [:]) -> Bool {
        return Sdk.sharedInstance.application(application, open: url, options: options)
    }
}
```

- Trong lúc tích hợp và test, hãy đổi `environment` sang `.dev`:

```swift
Sdk.sharedInstance.initWithDelegate(self, application: application, launchOptions: launchOptions, environment: .dev)
```

Cài đặt các callback của `SdkDelegate` (tất cả đều optional, chỉ implement những cái bạn cần) trong một extension của `AppDelegate`:

```swift
extension AppDelegate {

    func sdk(_ sdk: Sdk, loginSuccess user: User, accessToken: String, refreshToken: String) {
        // Đăng nhập thành công — user.accountID, user.accountName
    }

    func sdk(_ sdk: Sdk, logout user: User) {
        // Đăng xuất thành công
    }

    func sdk(_ sdk: Sdk, didPurchaseSuccess transactionInfo: TransactionInfo) {
        // Thanh toán thành công — transactionInfo.productId, transactionInfo.transId...
    }

    func sdk(_ sdk: Sdk, didPurchaseFailed transactionInfo: TransactionInfo, purchaseError: String?) {
        // Thanh toán thất bại
    }

    func sdk(_ sdk: Sdk, getLanguage language: String) {
        // Ngôn ngữ SDK vừa thay đổi
    }

    func sdkCloseLoginView() {
        // Màn hình đăng nhập vừa được đóng
    }
}
```

:::note
SDK bản Swift tự động xử lý việc xin quyền (notification, App Tracking Transparency) trong lúc khởi tạo — không có hàm bật/tắt popup xin quyền thủ công như bản Objective-C cũ.
:::

### 3.2. Đăng nhập (Login)

Luôn gọi hàm `login()` **trước khi game bắt đầu**. SDK sẽ tự hiển thị dialog đăng nhập nếu đây là lần đầu người dùng vào game, hoặc tự động refresh token nếu người dùng đã từng đăng nhập trước đó.

```swift
Sdk.sharedInstance.login()
```

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image8.png)

Nếu mọi thứ thành công, dialog đăng nhập sẽ hiển thị như hình trên.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image9.png)

Khi người dùng đăng nhập thành công, thông tin user sẽ được trả về qua callback `sdk(_:loginSuccess:accessToken:refreshToken:)` của `SdkDelegate` mà bạn đã đăng ký với SDK.

### 3.3. Đăng xuất (Logout)

```swift
Sdk.sharedInstance.logout()
```

Khi đăng xuất thành công, SDK sẽ gọi lại callback `sdk(_:logout:)` để thông báo cho game. Ngoài ra còn có `Sdk.sharedInstance.forceLogout()` — đăng xuất ngay lập tức mà không gọi API huỷ refresh token phía server (dùng khi phiên đăng nhập đã hết hạn phía server).

### 3.4. Lấy danh sách sản phẩm (List products)

Lấy danh sách sản phẩm (gói nạp) từ App Store. Bạn nên gọi hàm này ngay sau khi đăng nhập thành công, vì cần dùng giá sản phẩm để gửi lên hệ thống tracking khi người dùng thanh toán.

```swift
func sdk(_ sdk: Sdk, loginSuccess user: User, accessToken: String, refreshToken: String) {
    Sdk.sharedInstance.listProducts { error, products in
        // products: [IAPProduct]?
    }
    Sdk.sharedInstance.showOrHideFloatingButton()
}
```

:::note
Nên đặt lệnh gọi `listProducts` trong callback `loginSuccess`, như ví dụ trên — không cần chờ gì thêm.
:::

### 3.5. Đổi ngôn ngữ (Set Language)

Gọi hàm sau để đổi ngôn ngữ hiển thị của SDK:

```swift
Sdk.sharedInstance.setLanguage(input: "vi")
```

Các mã ngôn ngữ được hỗ trợ:

| Mã | Ngôn ngữ |
| --- | --- |
| `vi` | Tiếng Việt |
| `en` | Tiếng Anh |
| `th` | Tiếng Thái |
| `zh` | Tiếng Trung |

SDK cũng gọi lại callback `sdk(_:getLanguage:)` của `SdkDelegate` mỗi khi ngôn ngữ được thay đổi (bao gồm cả lần đầu khởi tạo).

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image10.png)

### 3.6. Hiển thị đếm ngược (Show countdown)

Để hiển thị giao diện đếm ngược như hình dưới, gọi `showCountdown()` **sau khi đăng nhập hoàn tất**:

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image11.png)

```swift
func sdk(_ sdk: Sdk, loginSuccess user: User, accessToken: String, refreshToken: String) {
    Sdk.sharedInstance.listProducts { error, products in }
    Sdk.sharedInstance.showOrHideFloatingButton()
    Sdk.sharedInstance.showCountdown()
}
```

Bạn có thể kiểm tra trước xem sự kiện đếm ngược có đang khả dụng không bằng `Sdk.sharedInstance.isCountdownAvailable() -> Bool`.

### 3.7. Nhận quà (Receive Gift)

```swift
Sdk.sharedInstance.showReceiveGift()
```

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image13.png)

:::note
Hàm này không nhận tham số — SDK tự lấy `characterId`/`serverId` đã lưu từ lần gọi `mappingUser(...)` gần nhất ([mục 3.10](#310-ánh-xạ-thông-tin-nhân-vật-map-user)). Vì vậy bạn cần gọi `mappingUser` trước khi hiển thị nút nhận quà.
:::

### 3.8. Thanh toán (Make payment)

```swift
Sdk.sharedInstance.payProduct(itemProduct.productId ?? "", forCharacterId: "17782088632480", onServerId: "s6003")
```

- Tham số đầu (`productID`): lấy từ `productId` của một `IAPProduct` trong kết quả `listProducts` ở [mục 3.4](#34-lấy-danh-sách-sản-phẩm-list-products).
- `forCharacterId`: Id nhân vật trong game.
- `onServerId`: Id server.

Kết quả thanh toán (thành công hoặc thất bại) sẽ được trả về tương ứng qua callback `sdk(_:didPurchaseSuccess:)` hoặc `sdk(_:didPurchaseFailed:purchaseError:)` của `SdkDelegate`.

### 3.9. Hiện/ẩn floating button (Show dashboard)

```swift
Sdk.sharedInstance.showOrHideFloatingButton()
```

### 3.10. Ánh xạ thông tin nhân vật (Map User)

Gọi hàm này để gửi thông tin nhân vật hiện tại của người dùng lên SDK, phục vụ cho tracking và các tính năng liên quan đến nhân vật/server (bao gồm cả `showReceiveGift()` ở [mục 3.7](#37-nhận-quà-receive-gift)):

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image12.png)

```swift
Sdk.sharedInstance.mappingUser(
    "name",
    characterId: "1",
    characterLevel: "1",
    serverName: "test",
    serverId: "1"
)
```

- Tham số đầu (không có nhãn): tên nhân vật.
- `characterId`: Id của nhân vật.
- `characterLevel`: Level hiện tại của nhân vật.
- `serverName`: Tên server.
- `serverId`: Id server.

SDK còn có `Sdk.sharedInstance.levelUpUser(_:characterId:characterLevel:serverName:serverId:vip:)` — gọi mỗi khi nhân vật lên level hoặc lên VIP, để hệ thống tracking ghi nhận mốc đạt được.

## 4. Hàm ghi log tracking (SdkTracking)

Các hàm dưới đây nằm trên singleton **`SdkTracking.shared`** (khác với `Sdk.sharedInstance`), dùng để gửi sự kiện tracking về hệ thống, giúp đo lường hành vi người dùng trong toàn bộ vòng đời chơi game — từ mở app, tải patch, tạo nhân vật đến vào game.

Chú thích màu trong sơ đồ Flowchart gốc:

- **Màu xám**: các bước xử lý phía Game.
- **Màu vàng**: các điểm Game cần gọi hàm của SDK.

Vui lòng xem thêm mục "Login or Start Game" trong [Flowchart](#6-sơ-đồ-luồng-flowchart) để biết vị trí chính xác cần đặt các hàm log bên dưới trong luồng chạy của game.

```swift
SdkTracking.shared.logStartGameScreen()
SdkTracking.shared.logEnterGamePlay()
SdkTracking.shared.logStartTutorial()
SdkTracking.shared.logCompleteTutorial()
```

#### `logEnterGamePlay()`

Tracking sự kiện người dùng vào màn hình gameplay, ngay sau khi bấm nút "Enter Game".

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image14.png)

#### `logPatchStart` — Bắt đầu tải tài nguyên (patch)

```swift
SdkTracking.shared.logPatchStart(sizeMB: 500, withVerrsion: "1.0.1", withNetworkType: "wifi")
```

| Tham số | Ý nghĩa |
| --- | --- |
| `sizeMB` | Dung lượng file patch cần tải, tính theo MB |
| `withVerrsion` | Phiên bản gói cài đặt |
| `withNetworkType` | Loại mạng (`"wifi"`, `"4g"`...) |

#### `logPatchSuccess` — Tải tài nguyên hoàn tất

```swift
SdkTracking.shared.logPatchSuccess(durationSec: 450, withAvgSpeedKbps: 111, withCdnNode: "192.168.0.2")
```

| Tham số | Ý nghĩa |
| --- | --- |
| `durationSec` | Thời gian từ lúc bắt đầu tải đến khi tải xong (giây) |
| `withAvgSpeedKbps` | Tốc độ tải trung bình (Kbps) |
| `withCdnNode` | Node CDN đã sử dụng để tải |

#### `logPatchError` — Tải tài nguyên thất bại

```swift
SdkTracking.shared.logPatchError(errorCode: "500", withRetryCount: 1, withFailedUrl: "https://cdn.game.com/patch/v120.zip", withCdnNode: "192.168.0.2")
```

| Tham số | Ý nghĩa |
| --- | --- |
| `errorCode` | Mã lỗi |
| `withRetryCount` | Số lần đã retry do lỗi |
| `withFailedUrl` | URL bị lỗi khi tải |
| `withCdnNode` | Node CDN xảy ra lỗi |

#### `logExtractStarted` — Bắt đầu giải nén tài nguyên

```swift
SdkTracking.shared.logExtractStarted(totalSizeMb: "500", withTotalSize: "400")
```

| Tham số | Ý nghĩa |
| --- | --- |
| `totalSizeMb` | Dung lượng sau khi giải nén, tính theo MB |
| `withTotalSize` | Số lượng file trong patch cần giải nén |

#### `logExtractFinished` — Giải nén hoàn tất

```swift
SdkTracking.shared.logExtractFinished(durationSec: 100, withResultCode: "ok")
```

| Tham số | Ý nghĩa |
| --- | --- |
| `durationSec` | Thời gian từ lúc bắt đầu giải nén đến khi hoàn tất (giây) |
| `withResultCode` | Mã kết quả — `"ok"`/`0`: OK, `1`: Disk Full |

#### `logCharCreateStart` — Bắt đầu tạo nhân vật

```swift
SdkTracking.shared.logCharCreateStart(serverId: "100")
```

:::note
Nên cài một timer nội bộ để tự đo thời gian từ lúc bắt đầu tạo nhân vật đến khi tạo xong — giá trị này cần truyền vào `logCharCreateSuccess` bên dưới.
:::

#### `logCharCreateSuccess` — Tạo nhân vật thành công

```swift
SdkTracking.shared.logCharCreateSuccess(
    serverId: "100",
    withCharId: "1001",
    withCharName: "test",
    withCharClass: "1",
    withDurationSec: 5
)
```

| Tham số | Ý nghĩa |
| --- | --- |
| `serverId` | Id server |
| `withCharId` | Id nhân vật |
| `withCharName` | Tên nhân vật |
| `withCharClass` | Id lớp nhân vật (class_id) |
| `withDurationSec` | Thời gian từ lúc bắt đầu tạo đến khi tạo thành công (giây) |

#### `logCharCreateError` — Tạo nhân vật thất bại

```swift
SdkTracking.shared.logCharCreateError(errorCode: "NAME_DUPLICATED", withCharName: "test", withServerId: "1")
```

#### `logCharSelect` — Chọn nhân vật

Gọi hàm này ngay sau khi người dùng chọn server và nhân vật để vào game.

```swift
SdkTracking.shared.logCharSelect("1", withCharacterName: "name", withCharLevel: "1")
```

## 5. Cập nhật đồng bộ thông tin theo Nghị định 147

Khác với bản Objective-C cũ (2 hàm `isNeedShowEventProfileSync` + `showEventProfile` gọi thủ công), bản Swift gộp thành **một hàm duy nhất** `checkShow147`, và SDK **tự hiển thị màn hình** đồng bộ thông tin nếu cần — bạn chỉ cần gọi và (tuỳ chọn) đọc kết quả qua completion:

```swift
Sdk.sharedInstance.checkShow147 { needVerify in
    // needVerify == true: SDK đã tự mở màn hình đồng bộ thông tin (Event Profile)
    // needVerify == false: không cần làm gì thêm, có thể cho người dùng vào game
}
```

Nên gọi ngay trong callback `loginSuccess`, trước khi cho vào màn hình chính của game.

## 6. Gợi ý đánh giá ứng dụng (Review App)

## 7. Các lớp/kiểu dữ liệu chính trong SDK

**`IAPProduct`** — thông tin một sản phẩm (gói nạp):

| Thuộc tính | Mô tả |
| --- | --- |
| `productId` | Id sản phẩm, trùng với product id khai báo trên App Store |
| `productDescription` | Mô tả sản phẩm |
| `localizedPrice` | Giá sản phẩm hiển thị theo locale của thiết bị |
| `price` / `currencyCode` / `priceLocale` | Giá gốc, mã tiền tệ, locale (dùng khi cần tự format giá) |
| `appAmount` | Số lượng gold/vàng người dùng nhận được khi mua gói này |
| `amount` | Số vXu tương ứng |

**`User`** — thông tin người dùng:

| Thuộc tính | Mô tả |
| --- | --- |
| `accountID` | Id tài khoản người dùng |
| `accountName` | Username của tài khoản |

**`TransactionInfo`** — thông tin giao dịch thanh toán (trả về qua `didPurchaseSuccess`/`didPurchaseFailed`):

| Thuộc tính | Mô tả |
| --- | --- |
| `transId` | Id giao dịch |
| `productId` | Id sản phẩm đã mua |
| `purchasedToken` | Token xác nhận giao dịch từ App Store |
| `paymentOrderId` | Id đơn hàng phía hệ thống thanh toán |
| `confirmByServer` | Trạng thái xác nhận từ server |

**`Sdk`** — singleton chính của SDK:

| Thành phần | Mô tả |
| --- | --- |
| `Sdk.sharedInstance` | Singleton của SDK |
| `delegate: SdkDelegate?` | Nơi nhận các callback (login, logout, thanh toán...) |
| `environment: Environment` | `.prod` hoặc `.dev` |
| `getCurrentAccessToken() -> String` | Lấy access token hiện tại sau khi đăng nhập thành công |

Chúng tôi sẽ cung cấp cho bạn các certificate cần thiết để build file `.ipa`, bao gồm: `apn_certificate`, `dev_certificate`, `dis_certificate`, development provisioning profile và production provisioning profile.

**Bước 1 — Import certificate vào Keychain:** double-click (hoặc kéo thả) file `.p12` để thêm vào Keychain Access.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image20.png)

**Bước 2 — Import provisioning profile vào Xcode:** double-click file provisioning profile (hoặc kéo thả vào Xcode) để Xcode tự nhận diện.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image21.png)

:::caution[Sai Client ID / Client Secret]
Nếu Client ID hoặc Client Secret cấu hình sai, bạn sẽ thấy thông báo lỗi ký (code signing) như hình dưới. Hãy vào mục **Signing & Capabilities**, kiểm tra lại và chọn đúng **Code Sign Identity** tương ứng với provisioning profile đã import.

Nếu vẫn gặp lỗi khi build file IPA liên quan đến provisioning, vui lòng kiểm tra kỹ lại bundle id, team và certificate đã dùng để tạo provisioning profile đó.
:::

### Cách export file IPA để upload lên App Store

:::danger[Cần đối chiếu lại]
Tài liệu gốc chỉ có ảnh chụp màn hình cho các bước này, không kèm mô tả bằng chữ. Nội dung 7 bước dưới đây do đội ngũ tài liệu diễn giải lại theo quy trình archive/export chuẩn của Xcode — vui lòng đối chiếu với ảnh chụp màn hình thực tế bên dưới trước khi làm theo, và báo lại nếu có bước nào không khớp.
:::

Làm theo các bước sau trong Xcode:

1. Chọn đích build là **Any iOS Device (arm64)** thay vì simulator.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image23.jpg)

2. Vào menu **Product > Archive** để Xcode build và đóng gói archive.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image24.jpg)

3. Sau khi archive xong, cửa sổ **Organizer** sẽ tự mở và hiển thị bản archive vừa tạo. Chọn **Distribute App**.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image25.jpg)

4. Chọn phương thức phân phối phù hợp (ví dụ **App Store Connect** hoặc **Ad Hoc**) và làm theo các bước wizard của Xcode.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image26.jpg)

5. Trước khi export, nhớ kiểm tra kỹ mục **aps-environment** trong entitlements phải là `production` (không phải `development`), nếu không push notification sẽ không hoạt động trên bản release.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image27.png)

6. Sau khi export xong, chọn **Show in Finder** để mở thư mục chứa file `.ipa`.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image28.png)

7. Chuột phải vào file `.ipa` (hoặc file `.xcarchive`) và chọn **Show Package Contents** để lấy file dSYM bên trong nếu cần gửi debug symbol.

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image29.png)

![](BASE_STORAGE/v2.0.0/ios_swift_integration_guide_image30.png)

:::note
Khi cần hỗ trợ debug, vui lòng gửi cho đội ngũ VTVLive cả file **dSYM** và file **.ipa** tương ứng.
:::
