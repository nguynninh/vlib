Trang này liệt kê lịch sử phát hành (release) của iTapSDK trên iOS, theo từng **dòng SDK** riêng biệt (Game SDK, OIDC v2, ON Live, SeeNow). Mỗi dòng SDK có version tăng dần độc lập với nhau — hãy chọn đúng bảng tương ứng với dòng SDK mà bạn đang tích hợp.

Ý nghĩa các cột trong bảng:

- **Phiên bản**: tên định danh của bản phát hành.
- **File**: link tải file `.xcframework` (hoặc file cấu hình) của phiên bản đó.
- **Mã commit**: mã commit trên hệ thống quản lý mã nguồn tương ứng với bản build này.
- **MD5**: mã kiểm tra toàn vẹn (checksum) của file, dùng để xác nhận file tải về không bị lỗi/sai khác.
- **Ngày phát hành**: thời điểm bản này được phát hành.
- **Thay đổi**: tóm tắt các thay đổi chính so với bản trước.

:::note
Một số ô để trống do đội phát triển chưa cập nhật đầy đủ thông tin (mã commit, MD5, ngày phát hành...) tại thời điểm phát hành. Nếu bạn cần thông tin còn thiếu, vui lòng liên hệ đội ngũ VTVLive.
:::
