## 1.0.0

### Đã thêm

- Bộ tài liệu SDK Game cho Android và iOS, gồm tổng quan, tài liệu tích hợp, tài liệu API, mô tả luồng sự kiện và các tính năng SDK.
- Tài liệu tích hợp Game v2 OIDC cho Android và iOS.
- Tab **Nhật ký thay đổi** để ghi lại các cập nhật theo từng phiên bản tài liệu.

### Đã cập nhật

- Chuẩn hoá cấu trúc tài liệu SDK Game theo nhóm **Tổng quan**, **Tài liệu tích hợp**, **Tài liệu API**, **Luồng sự kiện**, **Tính năng SDK**, **Android** và **iOS**.
- Bổ sung nội dung nền tảng cho bản tài liệu đầu tiên `1.0.0`.
