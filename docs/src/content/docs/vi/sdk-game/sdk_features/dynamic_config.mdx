## Tổng quan

1. Mục đích

    1. Giảm thiểu sự sai sót về cấu hình khi tích hợp với đối tác

    2. Tuỳ biến được domain, cấu hình trong các trường hợp khẩn cấp, tránh việc phải build lại SDK -> review lại ứng dụng.

2. Thông tin thêm

    SDK sẽ ưu tiên lấy cấu hình từ BE API. Nếu API gọi thất bại hoặc dữ liệu trả về không giải mã được, SDK sẽ tự động fallback sang Firebase Remote Config. Trường hợp cả hai nguồn đều thất bại, SDK sẽ sử dụng cấu hình đã được lưu trước đó trong SharedPreferences (hoặc cấu hình mặc định trong file Firebase XML nếu là lần đầu cài đặt).

## API

1. Sơ đồ luồng

    - Android

```mermaid
%% width: 1100
flowchart LR
    Start((Khởi động)) --> FirstInstall{Lần Đầu<br/>Cài Đặt}
    FirstInstall -- true --> SaveDefault[Lưu cấu hình từ file<br/>Firebase XML Mặc<br/>định xuống<br/>SharedPreferences]
    SaveDefault --> RemoteApi[Api Remote Config]
    FirstInstall -- false --> RemoteApi

    RemoteApi --> ApiState{Trạng Thái<br/>Api}
    ApiState -- "Thành Công" --> DecodeApi{Giải mã}
    ApiState -- "thất bại" --> DecodeApi

    DecodeApi -- "thất bại" --> FirebaseRemote[Firebase Remote<br/>Config]
    ApiState -- "thất bại" --> FirebaseRemote
    FirebaseRemote --> FirebaseState{Trạng Thái<br/>Firebase}
    FirebaseState -- "thành công" --> DecodeFirebase{Giải mã}
    FirebaseState -- "thất bại" --> InitAppInfo[Khởi tạo AppInfo từ<br/>SharedPreferences]

    DecodeFirebase -- "thành công" --> SaveConfig[Lưu cấu hình xuống<br/>SharedPreferences]
    DecodeApi -- "thành công" --> SaveConfig

    SaveConfig --> CheckDomain{Kiểm tra Id Domain<br/>thay đổi}
    CheckDomain -- true --> Logout[Đăng xuất]

    SaveConfig --> InitAppInfo
    InitAppInfo --> Done((Done))
```

    - IOS

```mermaid
%% width: 1100
flowchart LR
    Start((khởi động app)) --> A[Call api lấy config động]
    A --> B{trạng thái trả về api}
    B -->|true| C{kiểm tra dữ liệu}
    B -->|false| D[lấy cấu hình từ firebase config]
    D --> E{trạng thái trả về từ firebase}
    E -->|true| C
    E -->|false| F[lấy dữ default từ app config]
    C -->|false| F
    C -->|true| G{so sánh với dữ liệu usedefault}
    F --> G
    G -->|userDefault # nil| H{so sánh domain}
    G -->|userDefault nil| K[Lưu xuống userDefault]
    H -->|khác nhau| I[logout]
    H -->|giống| K
    I --> K
    K --> End((kết thúc))
```
