Trang này hướng dẫn tích hợp nhanh SDK vào một project Android (Java) thực tế, theo đúng cấu trúc của project mẫu `Integration Sdk Game Example`. Để xem đầy đủ toàn bộ tính năng của SDK (đa ngôn ngữ, tracking chi tiết, floating button...), xem thêm [Hướng dẫn dành cho nhà phát triển](/sdk-game/android/java/guides). Để lấy thông tin cấu hình (client_id, client_secret, key nội bộ...), xem [Hướng dẫn cấu hình](/sdk-game/android/java/dev_config).

## 1. Danh sách file cần thiết

Trước khi tích hợp, bạn cần chuẩn bị đầy đủ các file sau (do đội ngũ VTVLive cung cấp):

1. Thư mục `res` (icon, resource cấu hình SDK)
2. `strings.xml`
3. `keysdk.txt` — chứa access token riêng để tải thư viện SDK từ Maven nội bộ
4. Thư mục `icon app`
5. Thư mục `keystore` (file `.jks` và thông tin ký ứng dụng)
6. `google-services.json`
7. Project demo mẫu (`Integration Sdk Game Example`)

:::caution
`keysdk.txt` và thư mục `keystore` chứa thông tin bí mật (access token, mật khẩu keystore) — tuyệt đối không commit các file này lên repo public, và không dán trực tiếp vào tài liệu chia sẻ rộng rãi.
:::

## 2. Cấu hình Gradle

### 2.1. `settings.gradle` — khai báo repository Maven nội bộ

```groovy
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }
        maven {
            url "https://source.vtvlive.vn/api/v4/projects/2352/packages/maven"
            credentials(HttpHeaderCredentials) {
                name = "Private-Token"
                value = "<PRIVATE_TOKEN_1>" // lấy giá trị thật trong keysdk.txt
            }
            authentication {
                header(HttpHeaderAuthentication)
            }
        }
        maven {
            url 'https://source.vtvlive.vn/api/v4/projects/2558/packages/maven'
            credentials(HttpHeaderCredentials) {
                name = "Private-Token"
                value = "<PRIVATE_TOKEN_2>" // lấy giá trị thật trong keysdk.txt
            }
            authentication {
                header(HttpHeaderAuthentication)
            }
        }
    }
}
```

:::danger[Không dùng token thật trong tài liệu]
Hai giá trị `Private-Token` ở trên phải lấy từ file `keysdk.txt` mà VTVLive cung cấp riêng cho từng đối tác — **không** copy token của đối tác khác hoặc để lộ token trong mã nguồn public.
:::

:::note
Ví dụ trên lấy đúng từ project mẫu (phiên bản SDK `1.3.8`). Trước khi release, kiểm tra lại phiên bản ổn định mới nhất tại [Hướng dẫn dành cho nhà phát triển](/sdk-game/android/java/guides#cài-đặt-sdk).
:::

### 2.4. Thêm file cấu hình vào project

1. Giải nén `res.zip`, sao chép và ghi đè vào thư mục `res` của project (bao gồm `xml/vtvlive_config_sdk_game_defaults.xml` và các thư mục `drawable-*`).
2. Sao chép các tham số Facebook từ `strings.xml` được cung cấp vào `strings.xml` của project bạn (`facebook_app_id`, `fb_login_protocol_scheme`, `facebook_client_token`).
3. Sao chép `google-services.json` vào thư mục gốc của module `app`.

## 3. Khai báo `AndroidManifest.xml`

Activity chính chỉ cần khai báo bình thường như một Activity launcher — SDK không yêu cầu permission hay component đặc biệt nào thêm ở bước này:

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:supportsRtl="true"
        android:theme="@style/AppTheme">
        <activity
            android:name=".MainActivity"
            android:configChanges="keyboard|keyboardHidden|screenLayout|screenSize|orientation|locale|layoutDirection"
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>
    </application>
</manifest>
```

:::note
Thuộc tính `android:configChanges` cần đủ các giá trị trên (đặc biệt `orientation`, `screenSize`) để Activity không bị restart khi xoay màn hình — SDK xử lý việc xoay UI floating button riêng qua `resetFloatingButton()` (xem [mục 5](#5-xử-lý-khi-xoay-màn-hình)).
:::

## 4. Khởi tạo và đăng nhập SDK

Đây là toàn bộ code tích hợp tối thiểu, lấy nguyên từ `MainActivity.java` của project mẫu:

```java
package vn.vplay.ngaothevolam.t035a;

import android.app.Activity;
import android.content.res.Configuration;
import android.os.Bundle;
import android.util.Log;
import android.view.Window;
import android.view.WindowManager;
import android.widget.Button;

import org.jetbrains.annotations.NotNull;

import vlive.sdk.game.VLiveSdkGame;
import vlive.sdk.game.callback.AuthenticationListener;
import vlive.sdk.game.callback.PaymentListener;
import vlive.sdk.game.enumext.EnvironmentSdk;
import vlive.sdk.game.model.UserInfo;

public class MainActivity extends Activity implements AuthenticationListener, PaymentListener {

    private Button btnLogin;
    private Button btnLogout;
    private Button btnPayment;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        requestWindowFeature(Window.FEATURE_NO_TITLE);
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        getWindow().setFlags(WindowManager.LayoutParams.FLAG_FULLSCREEN, WindowManager.LayoutParams.FLAG_FULLSCREEN);

        btnLogin = findViewById(R.id.btnLogin);
        btnLogout = findViewById(R.id.btnDashboard);
        btnPayment = findViewById(R.id.btnListProduct);
        bindOnClickListener();

        // Khởi tạo SDK
        VLiveSdkGame vLiveSdkGame = VLiveSdkGame.getInstance();
        vLiveSdkGame.setEnvironment(EnvironmentSdk.Production); // đổi sang .Development khi test
        vLiveSdkGame.setActivity(this);
        vLiveSdkGame.setAuthenticationListener(this);
        vLiveSdkGame.setPaymentListener(this);

        // Tự động đăng nhập khi SDK khởi tạo xong
        vLiveSdkGame.setInitStatusListener(isCreated -> {
            if (isCreated) {
                VLiveSdkGame.getInstance().login();
            }
        });
    }

    private void bindOnClickListener() {
        btnLogin.setOnClickListener(v -> VLiveSdkGame.getInstance().login());
        btnLogout.setOnClickListener(v -> VLiveSdkGame.getInstance().logout());
        btnPayment.setOnClickListener(v -> {
            String productId = "vn.vplay.ngaothevolam.t035a.79";
            String characterId = "324132321";
            String serverId = "123";
            VLiveSdkGame.getInstance().payProduct(productId, characterId, serverId);
        });
    }

    @Override
    public void onLoginSuccessful(UserInfo userInfo, String accessToken, String refreshToken, String idToken) {
        Log.i("TAG GAME", "userInfoId: " + userInfo.getUserId());
        Log.i("TAG GAME", "userInfoName: " + userInfo.getUserName());
    }

    @Override
    public void onLogoutSuccessful() {
        Log.i("TAG GAME", "LogOut");
    }

    @Override
    public void onPayProductSuccess(String orderId, String productId) {
        Log.i("TAG GAME", "Payment " + orderId + " " + productId);
    }

    @Override
    public void onPayProductError(String error) {
        Log.i("TAG GAME", "Payment error: " + error);
    }
}
```

Ý nghĩa các bước khởi tạo:

- `setEnvironment(...)` — chọn môi trường `Production` hoặc `Development`.
- `setActivity(this)` — Activity dùng để SDK hiển thị UI (login, floating button...).
- `setAuthenticationListener(this)` / `setPaymentListener(this)` — Activity phải implement `AuthenticationListener` và `PaymentListener` để nhận callback.
- `setInitStatusListener(...)` — callback báo SDK đã khởi tạo xong hay chưa; nên gọi `login()` trong callback này thay vì gọi ngay trong `onCreate`.

## 5. Xử lý khi xoay màn hình

```java
@Override
public void onConfigurationChanged(@NotNull Configuration newConfig) {
    super.onConfigurationChanged(newConfig);
    VLiveSdkGame.getInstance().resetFloatingButton();
}
```

Sau khi chạy được luồng khởi tạo → đăng nhập → thanh toán ở trên, tiếp tục hoàn thiện tích hợp theo:

- [Hướng dẫn dành cho nhà phát triển](/sdk-game/android/java/guides) — tracking sự kiện bắt buộc (patch, extract, character, map user...), đa ngôn ngữ, floating button, ProGuard, kiểm tra phiên bản trước khi build.
- [Hướng dẫn cấu hình](/sdk-game/android/java/dev_config) — lấy `client_id`, `client_secret` và cấu hình Hub/Firebase Remote Config.
- [Luồng kiểm tra khi tích hợp SDK](/sdk-game/android/java/integrate) — checklist trước khi gửi APK/AAB để VTVLive rà soát.
