Trang này liệt kê lịch sử phát hành (release) của VTV Live Android Game SDK.

Ý nghĩa các cột trong bảng:

- **Phiên bản**: tên định danh của bản phát hành.
- **File**: link tải file `.aar`/Maven artifact của phiên bản đó.
- **Mã commit**: mã commit trên hệ thống quản lý mã nguồn tương ứng với bản build này.
- **Ngày phát hành**: thời điểm bản này được phát hành.
- **Thay đổi**: tóm tắt các thay đổi chính so với bản trước.

:::note
Trang này mới khởi tạo, chưa có đầy đủ lịch sử các phiên bản đã phát hành trước đó. Nếu bạn cần thông tin của một phiên bản cụ thể, vui lòng liên hệ đội ngũ VTVLive.
:::
