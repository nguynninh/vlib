Nền tảng Web Documentation cung cấp một tập hợp tính năng nhằm giúp việc viết, đọc và duy trì tài liệu kỹ thuật trở nên dễ dàng hơn.

## Nội dung bằng MDX

Tài liệu được viết bằng **MDX**, kết hợp cú pháp Markdown quen thuộc với khả năng nhúng component.

* Hỗ trợ đầy đủ cú pháp Markdown: heading, danh sách, bảng, blockquote...
* Cho phép nhúng component tuỳ biến (ví dụ `<Tabs>`, `<TabItem>`) ngay trong nội dung.
* Mỗi trang có frontmatter riêng (`title`, `description`) phục vụ SEO và điều hướng.

## Khối mã và số dòng

Khối mã sử dụng Expressive Code, hỗ trợ:

* Tô sáng cú pháp (syntax highlighting) cho nhiều ngôn ngữ lập trình.
* Hiển thị số dòng (`showLineNumbers`) khi cần tham chiếu đến dòng cụ thể.
* Đặt tiêu đề cho khối mã (`title="..."`) để mô tả file hoặc ngữ cảnh.

## Sơ đồ Mermaid

Nền tảng tích hợp **Mermaid** để vẽ sơ đồ trực tiếp từ code block, hỗ trợ:

* Flowchart, sequence diagram, class diagram...
* Sơ đồ ZenUML thông qua plugin `@mermaid-js/mermaid-zenuml`.
* Sơ đồ được render trực tiếp trong trang, không cần công cụ thiết kế bên ngoài.

## Khung chú thích (Callout)

Cú pháp `:::note`, `:::tip`, `:::caution`, `:::danger` giúp làm nổi bật thông tin quan trọng mà không cần rời khỏi mạch đọc chính của trang.

## Bảng nâng cao

Bảng Markdown được mở rộng thêm cú pháp `[width=...]` (thông qua remark plugin tuỳ biến) để kiểm soát độ rộng cột khi cần thiết.

## Tìm kiếm toàn văn

Toàn bộ tài liệu có thể được tìm kiếm theo nội dung (full-text search), giúp người đọc tìm nhanh trang chứa từ khoá mong muốn thay vì phải duyệt qua từng mục.

## Đa ngôn ngữ

Nền tảng hỗ trợ nhiều ngôn ngữ:

| Ngôn ngữ | Mã   |
| -------- | ---- |
| Tiếng Việt | `vi` |
| English    | `en` |
| 中文        | `zh` |
| 日本語      | `ja` |

Mỗi ngôn ngữ có một thư mục nội dung riêng, cho phép dịch và duy trì tài liệu độc lập theo từng locale.

## Giao diện sáng và tối

Giao diện tự động chuyển đổi giữa chủ đề sáng và tối theo lựa chọn của người dùng hoặc cài đặt hệ thống.

## Responsive

Giao diện được tối ưu để hiển thị tốt trên desktop, tablet và mobile, bao gồm cả các bảng nhiều cột và khối mã dài.

## Điều hướng và Mục lục

* Sidebar tự động sinh (`autogenerate`) dựa trên cấu trúc thư mục tài liệu.
* Mục lục (Table of Contents) tự động tạo từ các heading trong trang, giúp nhảy nhanh đến từng phần.

## Quản lý phiên bản qua Git

Tài liệu được lưu trữ dưới dạng file MDX trong repository, cho phép:

* Theo dõi lịch sử thay đổi nội dung.
* Review thay đổi tài liệu như review code, thông qua pull request.
* Khôi phục hoặc so sánh phiên bản cũ khi cần.
