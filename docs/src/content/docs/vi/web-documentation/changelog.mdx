## 1.0.0

### Đã thêm

- Trang [Kiểu chữ](/vi/web-documentation/ui/typography): hướng dẫn sử dụng tiêu đề, đoạn văn, in đậm, in nghiêng, gạch ngang, mã nguồn nội dòng, danh sách (không thứ tự, có thứ tự, công việc), trích dẫn, đường kẻ ngang, link, ảnh, xuống dòng, ký tự đặc biệt và các quy tắc trình bày văn bản trong tài liệu kỹ thuật.

### Đã cập nhật

- [Giới thiệu](/vi/web-documentation/overview/introduction): viết lại toàn bộ nội dung, chuyển từ nội dung mẫu tiếng Anh (tích hợp cổng thanh toán) sang giới thiệu đúng về nền tảng Web Documentation.
- [Tính năng](/vi/web-documentation/overview/features): bổ sung nội dung chi tiết cho từng tính năng (MDX, khối mã, Mermaid, khung chú thích, bảng nâng cao, tìm kiếm toàn văn, đa ngôn ngữ, giao diện sáng/tối, responsive, điều hướng, quản lý phiên bản qua Git).
- [Công nghệ sử dụng](/vi/web-documentation/overview/tech-stack): bổ sung bảng công nghệ, plugin Markdown tuỳ biến, cấu hình i18n, cấu trúc thư mục và hướng dẫn build & triển khai.
- [Media & Files](/vi/web-documentation/ui/media_file): thay các link ảnh/video/file mẫu trỏ trực tiếp đến GitHub Releases bằng biến `BASE_STORAGE` để dễ thay đổi nguồn lưu trữ.
- Cấu hình build (`astro.config.mjs`, `remark-media-options.mjs`): đọc biến `PORT` để đặt cổng chạy dev server, và tự động thay token `BASE_STORAGE` trong link media bằng giá trị thật lấy từ `.env` lúc build.
