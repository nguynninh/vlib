Web Documentation 平台提供了一系列功能，旨在让编写、阅读和维护技术文档变得更加轻松。

## MDX 内容

文档使用 **MDX** 编写，将熟悉的 Markdown 语法与嵌入组件的能力结合起来。

* 完整支持 Markdown 语法：标题、列表、表格、引用等。
* 允许在内容中直接嵌入自定义组件（例如 `<Tabs>`、`<TabItem>`）。
* 每个页面都有自己的 frontmatter（`title`、`description`），用于 SEO 和导航。

## 代码块与行号

代码块由 Expressive Code 提供支持，支持：

* 多种编程语言的语法高亮。
* 在需要引用特定行时显示行号（`showLineNumbers`）。
* 为代码块添加标题（`title="..."`），描述文件或上下文。

## Mermaid 图表

该平台集成了 **Mermaid**，可直接从代码块渲染图表，支持：

* 流程图、时序图、类图等。
* 通过 `@mermaid-js/mermaid-zenuml` 插件支持 ZenUML 图表。
* 图表直接在页面中渲染，无需借助任何外部设计工具。

## 提示框

`:::note`、`:::tip`、`:::caution`、`:::danger` 语法可以突出显示重要信息，而不会打断读者阅读页面主体内容的思路。

## 增强表格

通过自定义 remark 插件，Markdown 表格扩展了 `[width=...]` 语法，可在需要时控制列宽。

## 全文搜索

整个文档集支持按内容搜索，让读者可以快速跳转到包含所需关键字的页面，而无需逐个浏览章节。

## 多语言支持

该平台支持多种语言：

| 语言        | 代码 |
| ----------- | ---- |
| Tiếng Việt  | `vi` |
| English     | `en` |
| 中文        | `zh` |
| 日本語      | `ja` |

每种语言都有独立的内容目录，可以按语言环境（locale）独立维护翻译。

## 浅色与深色主题

界面会根据用户的选择或系统设置，自动在浅色和深色主题之间切换。

## 响应式布局

界面经过优化，可在桌面端、平板和移动端良好显示，包括宽表格和长代码块。

## 导航与目录

* 根据文档目录结构自动生成侧边栏（`autogenerate`）。
* 根据页面标题自动生成目录（Table of Contents），方便快速跳转到各个部分。

## 通过 Git 进行版本控制

文档以 MDX 文件的形式存储在仓库中，这使得：

* 可以追踪内容变更的历史记录。
* 可以像审查代码一样，通过 pull request 审查文档变更。
* 需要时可以恢复或比较旧版本。
