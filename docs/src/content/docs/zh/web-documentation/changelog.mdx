## 1.0.0

### 新增

- [排版](/zh/web-documentation/ui/typography) 页面:介绍标题、段落、粗体、斜体、删除线、行内代码、列表(无序、有序、任务)、引用、水平分割线、链接、图片、换行、特殊字符转义,以及技术文档中的文本呈现规范。

### 更新

- [简介](/zh/web-documentation/overview/introduction):重写了全部内容,从遗留的示例内容(支付网关集成)改为对 Web Documentation 平台的正确介绍。
- [功能特性](/zh/web-documentation/overview/features):为每项功能补充了详细内容(MDX、代码块、Mermaid、提示框、增强表格、全文搜索、多语言、浅色/深色主题、响应式布局、导航、通过 Git 进行版本控制)。
- [技术栈](/zh/web-documentation/overview/tech-stack):补充了技术栈表格、自定义 Markdown 插件、i18n 配置、目录结构以及构建与部署说明。
- [Media & Files](/zh/web-documentation/ui/media_file):将直接指向 GitHub Releases 的示例图片/视频/文件链接替换为 `BASE_STORAGE` 变量,便于更改存储来源。
- 构建配置(`astro.config.mjs`、`remark-media-options.mjs`):读取 `PORT` 变量以设置开发服务器端口,并在构建时自动将媒体链接中的 `BASE_STORAGE` 占位符替换为 `.env` 中的真实值。
