## 1.1.0

### 新增

- 全新的 Android(Java)**集成指南**，改为交互式分步应用，取代此前的静态 Markdown 页面。
- 支持通过侧边栏和页面分页直接深链接到指南中的具体步骤。

### 更新

- 将交互式指南的明暗显示与站点真实的主题切换同步，涵盖全部内容、代码块、Logcat 控制台以及媒体灯箱。
- 扩展 Android > Java 侧边栏，涵盖集成指南的所有步骤。
- 将以上全部内容同步翻译为英文、中文和日文。

### 移除

- 移除交互式指南内部的导航面板、进度条以及独立的"上一步/下一步"页脚，因其已与站点真实的侧边栏和分页重复。
- 移除指南内独立的语言切换下拉菜单；指南语言现在跟随站点的语言路由。

## 1.0.2

### 新增

- 新增 Android(Java)**集成指南**与**发布说明**页面,内容基于真实的 SDK 示例项目编写。
- 完全重写 iOS **Swift 集成指南**,改用真实的 Swift API(`Sdk`、`SdkDelegate`、`SdkTracking`),替换此前误从 Objective-C 页面复制的内容。

### 更新

- 重写 iOS Objective-C 的**集成指南**、**发布说明**以及 SDK 更新页面(5.0.0、5.1.4、5.3.1),使其更清晰易读;修正原文档中的错误/遗漏,并明确标注仍需核对的部分。
- 将侧边栏改为明确排序而非自动生成,并为全部 4 种语言(vi/en/zh/ja)的每个侧边栏条目补充翻译。
- 将以上全部内容同步翻译为英文、中文和日文。

### 移除

- 移除全部 4 种语言中已不再使用的旧版 SDK Game 文档页面(`sdk_features/*`、`tai_lieu_*`)。

## 1.0.0

### 新增

- Android 和 iOS 的 SDK Game 文档,包括概览、集成文档、API 文档、事件流程文档和 SDK 功能。
- Android 和 iOS 的 Game v2 OIDC 集成文档。
- **Changelog** 标签,用于按版本记录文档更新。

### 更新

- 将 SDK Game 文档结构标准化为 **Overview**、**Integration Documentation**、**API Documentation**、**Event Workflow**、**SDK Features**、**Android** 和 **iOS**。
- 补充文档版本 `1.0.0` 的基础内容。
