## 2. 上报到 Vlive Tracking 的事件（Hub Logs Collection）

目前上报到 Vlive 的事件按照 Hub Logs Collection 文档要求，存在无参数或参数较少的情况。尚未应用的新事件需要补充并重新统一。

### 上报事件到 sdk vlive tracking game 时的默认参数

- `deviceId`：设备识别 ID
- `deviceModel`：设备型号名称
- `deviceBrand`：设备品牌
- `deviceFullInfoJson`：JSON 格式的设备完整信息
- `deviceOs`：设备操作系统名称（例如：Android、iOS）
- `deviceOsVersion`：设备操作系统版本
- `appClientId`：应用的 client ID
- `appId`：应用 ID
- `appName`：应用名称
- `appCode`：应用代码
- `appPackage`：应用的 package 名称（例如：`com.example.app`）
- `appVersion`：应用版本
- `appSdkVersion`：应用的 SDK 版本

`deviceFullInfoJson` 包含以下参数：

- `width`：屏幕横向宽度（px）
- `height`：屏幕纵向高度（px）
- `density_dpi`：屏幕像素密度（DPI）
- `density`：屏幕缩放比例（例如：2.0、3.0）
- `serial`：设备序列号
- `model`：设备型号名称（例如：Pixel 8、SM-A525F）
- `id`：操作系统构建版本 ID
- `manufacture`：设备制造商（三星、小米、Oppo 等）
- `brand`：设备品牌
- `type`：操作系统构建类型（`user`、`userdebug`、`eng`）
- `user`：用于构建操作系统的用户名
- `base`：Android 平台初始版本代码（通常为 1）
- `incremental`：操作系统的递增构建代码
- `sdk`：Android API Level（例如：34）
- `board`：设备板卡/硬件名称
- `host`：用于构建操作系统的主机名
- `fingerprint`：设备/ROM 版本的唯一识别字符串
- `version_code`：向用户展示的 Android 版本（例如：14）
