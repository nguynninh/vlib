本页根据 `Integration Sdk Game Example` 示例项目的实际结构，指导你快速将 SDK 集成到一个实际的 Android（Java）项目中。要查看 SDK 的完整功能（多语言、详细跟踪、悬浮按钮等），请参阅[开发者指南](/sdk-game/android/java/guides)。要获取配置信息（client_id、client_secret、内部 key 等），请参阅[配置指南](/sdk-game/android/java/dev_config)。

## 1. 所需文件清单

在集成之前，你需要准备好以下文件（由 VTVLive 团队提供）：

1. `res` 目录（图标、SDK 配置资源）
2. `strings.xml`
3. `keysdk.txt` — 包含用于从内部 Maven 下载 SDK 库的专用 access token
4. `icon app` 目录
5. `keystore` 目录（`.jks` 文件及应用签名信息）
6. `google-services.json`
7. 示例演示项目（`Integration Sdk Game Example`）

:::caution
`keysdk.txt` 和 `keystore` 目录包含机密信息（access token、keystore 密码）— 切勿将这些文件提交到公开仓库，也不要直接粘贴到广泛共享的文档中。
:::

## 2. Gradle 配置

### 2.1. `settings.gradle` — 声明内部 Maven 仓库

```groovy
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }
        maven {
            url "https://source.vtvlive.vn/api/v4/projects/2352/packages/maven"
            credentials(HttpHeaderCredentials) {
                name = "Private-Token"
                value = "<PRIVATE_TOKEN_1>" // 从 keysdk.txt 中获取实际值
            }
            authentication {
                header(HttpHeaderAuthentication)
            }
        }
        maven {
            url 'https://source.vtvlive.vn/api/v4/projects/2558/packages/maven'
            credentials(HttpHeaderCredentials) {
                name = "Private-Token"
                value = "<PRIVATE_TOKEN_2>" // 从 keysdk.txt 中获取实际值
            }
            authentication {
                header(HttpHeaderAuthentication)
            }
        }
    }
}
```

:::danger[请勿在文档中使用真实 token]
上面两个 `Private-Token` 的值必须从 VTVLive 为每个合作伙伴单独提供的 `keysdk.txt` 文件中获取 —— **切勿**复制其他合作伙伴的 token，也不要在公开源代码中泄露 token。
:::

### 2.2. `build.gradle`（Project）

```groovy
buildscript {
    repositories {
        google()
        mavenCentral()
        jcenter()
        flatDir {
            dirs 'libs'
        }
    }
    dependencies {
        classpath 'com.android.tools.build:gradle:8.6.0'
        classpath 'com.google.firebase:perf-plugin:1.4.2'
        classpath 'com.google.gms:google-services:4.4.3'
        classpath 'com.google.firebase:firebase-crashlytics-gradle:3.0.6'
    }
}
```

### 2.3. `build.gradle`（App）

```groovy
plugins {
    id 'com.android.application'
    id 'com.google.firebase.firebase-perf'
    id 'com.google.gms.google-services'
    id 'com.google.firebase.crashlytics'

android {
    namespace 'vn.vplay.ngaothevolam.t035a' // 改为你的游戏 package name
    compileSdk 35

    defaultConfig {
        applicationId "vn.vplay.ngaothevolam.t035a" // 改为你的游戏 package name
        minSdk 24
        targetSdk 35
        versionCode 1
        versionName "1.0"
    }

    compileOptions {
        sourceCompatibility JavaVersion.VERSION_17
        targetCompatibility JavaVersion.VERSION_17
    }
}

dependencies {
    implementation "vn.vlive.sdk:game:1.3.8" // 最新稳定版本请查看开发者指南
}
```

:::note
以上示例直接取自示例项目（SDK 版本 `1.3.8`）。发布前，请在[开发者指南](/sdk-game/android/java/guides#cài-đặt-sdk)中确认最新的稳定版本。
:::

### 2.4. 将配置文件添加到项目中

1. 解压 `res.zip`，将内容复制并覆盖到项目的 `res` 目录中（包括 `xml/vtvlive_config_sdk_game_defaults.xml` 及各个 `drawable-*` 目录）。
2. 将提供的 `strings.xml` 中的 Facebook 相关参数（`facebook_app_id`、`fb_login_protocol_scheme`、`facebook_client_token`）复制到你项目的 `strings.xml` 中。
3. 将 `google-services.json` 复制到 `app` 模块的根目录中。

## 3. 声明 `AndroidManifest.xml`

主 Activity 只需按普通 launcher Activity 声明即可 —— 在此步骤中，SDK 不需要额外的权限或组件：

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:supportsRtl="true"
        android:theme="@style/AppTheme">
        <activity
            android:name=".MainActivity"
            android:configChanges="keyboard|keyboardHidden|screenLayout|screenSize|orientation|locale|layoutDirection"
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>
    </application>
</manifest>
```

:::note
`android:configChanges` 属性需要包含以上所有值（特别是 `orientation`、`screenSize`），以便屏幕旋转时 Activity 不会重启 —— SDK 通过 `resetFloatingButton()` 单独处理悬浮按钮 UI 的旋转（参见[第 5 节](#5-xử-lý-khi-xoay-màn-hình)）。
:::

## 4. 初始化并登录 SDK

以下是最简集成代码的完整内容，直接取自示例项目的 `MainActivity.java`：

```java
package vn.vplay.ngaothevolam.t035a;

import android.app.Activity;
import android.content.res.Configuration;
import android.os.Bundle;
import android.util.Log;
import android.view.Window;
import android.view.WindowManager;
import android.widget.Button;

import org.jetbrains.annotations.NotNull;

import vlive.sdk.game.VLiveSdkGame;
import vlive.sdk.game.callback.AuthenticationListener;
import vlive.sdk.game.callback.PaymentListener;
import vlive.sdk.game.enumext.EnvironmentSdk;
import vlive.sdk.game.model.UserInfo;

public class MainActivity extends Activity implements AuthenticationListener, PaymentListener {

    private Button btnLogin;
    private Button btnLogout;
    private Button btnPayment;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        requestWindowFeature(Window.FEATURE_NO_TITLE);
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        getWindow().setFlags(WindowManager.LayoutParams.FLAG_FULLSCREEN, WindowManager.LayoutParams.FLAG_FULLSCREEN);

        btnLogin = findViewById(R.id.btnLogin);
        btnLogout = findViewById(R.id.btnDashboard);
        btnPayment = findViewById(R.id.btnListProduct);
        bindOnClickListener();

        // 初始化 SDK
        VLiveSdkGame vLiveSdkGame = VLiveSdkGame.getInstance();
        vLiveSdkGame.setEnvironment(EnvironmentSdk.Production); // 测试时改为 .Development
        vLiveSdkGame.setActivity(this);
        vLiveSdkGame.setAuthenticationListener(this);
        vLiveSdkGame.setPaymentListener(this);

        // SDK 初始化完成后自动登录
        vLiveSdkGame.setInitStatusListener(isCreated -> {
            if (isCreated) {
                VLiveSdkGame.getInstance().login();
            }
        });
    }

    private void bindOnClickListener() {
        btnLogin.setOnClickListener(v -> VLiveSdkGame.getInstance().login());
        btnLogout.setOnClickListener(v -> VLiveSdkGame.getInstance().logout());
        btnPayment.setOnClickListener(v -> {
            String productId = "vn.vplay.ngaothevolam.t035a.79";
            String characterId = "324132321";
            String serverId = "123";
            VLiveSdkGame.getInstance().payProduct(productId, characterId, serverId);
        });
    }

    @Override
    public void onLoginSuccessful(UserInfo userInfo, String accessToken, String refreshToken, String idToken) {
        Log.i("TAG GAME", "userInfoId: " + userInfo.getUserId());
        Log.i("TAG GAME", "userInfoName: " + userInfo.getUserName());
    }

    @Override
    public void onLogoutSuccessful() {
        Log.i("TAG GAME", "LogOut");
    }

    @Override
    public void onPayProductSuccess(String orderId, String productId) {
        Log.i("TAG GAME", "Payment " + orderId + " " + productId);
    }

    @Override
    public void onPayProductError(String error) {
        Log.i("TAG GAME", "Payment error: " + error);
    }
}
```

初始化各步骤的含义：

- `setEnvironment(...)` — 选择 `Production` 或 `Development` 环境。
- `setActivity(this)` — SDK 用于显示 UI（登录、悬浮按钮等）的 Activity。
- `setAuthenticationListener(this)` / `setPaymentListener(this)` — Activity 必须实现 `AuthenticationListener` 和 `PaymentListener` 才能接收回调。
- `setInitStatusListener(...)` — 通知 SDK 是否已完成初始化的回调；建议在此回调中调用 `login()`，而不是在 `onCreate` 中直接调用。
