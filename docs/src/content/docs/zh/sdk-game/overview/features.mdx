SDK Game 提供一套标准化的基础功能，用于规范 VTV Live 生态系统内各游戏的账户业务与 tracking。

## OTP 验证

支持通过 OTP 验证码对用户邮箱和手机号进行验证，可用于游戏内注册、修改账户信息等通用流程。

## 忘记密码

提供完整的密码找回流程，让用户无需离开游戏即可恢复账户。

## 来自 BE API 与 Firebase Remote Config 的动态配置

SDK 支持游戏在运行时实时获取动态配置，来源包括：

* 系统内部的 BE API。
* Firebase Remote Config。

因此，配置的变更（功能开关、运营参数等）无需重新发布游戏构建版本即可生效。

## 游戏内领取礼物

通过统一的 API 支持游戏内领取礼物的流程，确保多个游戏共用礼物活动时的一致性。

## 请求更新用户信息

在用户进入游戏时自动检测并要求补全缺失的信息，确保账户数据完整，以支撑后续业务。

## Game hub tracking

记录用户与 game hub 之间的交互事件，用于行为分析与产品运营。

## 通知跟踪

跟踪用户对发送到游戏内的通知（notification）的接收与交互状态。

## play_time 事件

更新 `play_time` 事件的记录逻辑，用于衡量用户的实际游戏时长。

## 通用参考文档

除了各平台的功能之外，SDK Game 还提供适用于 Android 和 iOS 的通用参考文档：

* 按平台划分的集成文档，以及相关条款、政策链接。
* SDK 中使用的 API/IAP 文档：domain、path、参数及用途。
* 各 tracking 事件的流程说明文档，并附有用于广告优化的 MKT 事件说明。
