## 需求

1. 登录成功后，按 30 秒、1 分钟、3 分钟、5 分钟、15 分钟、30 分钟、1 小时的周期，此后每 1 小时定期触发一次。

2. 若角色创建成功，则将 play time 重置为 0，并按照 (1) 重新计算。

3. 若用户跨日游玩，则到达 UTC+7 时间 0 点时会自动将 play time 重置为 0，并按照 (1) 重新计算。

4. 若用户返回主屏幕 -> 暂停 play_time -> 用户在未被登出的情况下重新回到游戏 -> 从暂停时刻继续计算 playtime。

5. 若用户返回主屏幕后，再次进入游戏时已被登出，则从 (1) 重新开始计算。
