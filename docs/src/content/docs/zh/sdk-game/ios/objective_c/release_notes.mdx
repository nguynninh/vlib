本页列出了 iTapSDK 在 iOS 上按各个**独立 SDK 系列**（Game SDK、OIDC v2、ON Live、SeeNow）划分的发布（release）历史。每个 SDK 系列的版本号各自独立递增——请选择与您正在集成的 SDK 系列相对应的表格。

表格各列说明：

- **版本**：该发布版本的标识名称。
- **文件**：该版本 `.xcframework`（或配置文件）的下载链接。
- **提交号**：与此构建对应的源码管理系统中的提交（commit）号。
- **MD5**：文件的完整性校验码（checksum），用于确认下载的文件没有损坏或差异。
- **发布日期**：该版本发布的时间。
- **变更内容**：与上一版本相比的主要变更摘要。

:::note
部分单元格为空，是因为开发团队在发布时尚未完整更新相关信息（提交号、MD5、发布日期等）。如果您需要缺失的信息，请联系 VTVLive 团队。
:::
