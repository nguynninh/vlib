### 1.1. 公开属性

| 成员 | 类型 | 描述 |
|---|---|---|
| `valueTimePlay` | `Int`（只读） | app 通过 `receiveTrackingTime` 注入的最近播放秒数 |
| `receiveTrackingTime` | `(Int) -> Unit` | **为 VOD 流注入播放时间（秒）。** 以函数方式调用：`overlayManager.receiveTrackingTime(12)` |

### 1.2. 方法

| 函数 | 描述 | 备注 |
|---|---|---|
| `initToken(token: String, userId: String, bjName: String = "")` | 声明/清除登录会话 | 需在 `joinRoom` 之前调用。登出：`initToken("", "")`。若处于直播中会自动重新加入房间 |
| `joinRoom(mediaId: String, type: Int)` | 为某个内容开始互动会话 | `type = 1` LIVE，`type = 2` VOD。会自动 `cleanUp()` 旧会话 |
| `releaseAll()` | 释放全部资源：socket、WebView、dialog、tracking | 在 `onDestroy()` 或退出内容时调用 |
| `fetchInteractiveStatus(mediaId: String, callback: (Boolean) -> Unit)` | 询问服务器该内容是否支持互动 | 网络错误 → 返回 `false` |
| `showChartsInteractive(mediaId: String, userId: String, backgroundColorHeader: String? = null)` | 打开排行榜（全屏 DialogFragment） | `backgroundColorHeader` 为十六进制颜色码，例如 `"#139DED"` |
| `hideChartsInteractive()` | 关闭排行榜 | |
| `isDialogCharShowing(): Boolean` | 排行榜是否正在显示 | |
| `addPlayerListener(listener: PlayerChangeListener)` | 为 SDK 提供 player 状态（用于 `ckst` 事件） | 需在 `joinRoom` **之后**调用，以便 listener 也被绑定到 socket |
| `sendAction(data: JSONObject)` | *（实现 `OnOverlayListener`）*处理来自 WebView 的操作 | SDK 自动调用，app **无需**调用 |
| `onClickAdsOverlay(url: String)` | *（实现 `OnOverlayListener`）*使用外部浏览器打开广告 URL | SDK 自动调用 |

> `LifecycleOverlay` 目前是一个空接口（`onResume/onStop/onDestroy` 函数已在代码中被注释）
> —— SDK 除了 observe LiveData 之外，**不会**自行跟随 Activity 生命周期。

  </TabItem>

| Callback | 何时触发 | app 应做的事 |
|---|---|---|
| `onHandleMessage(NEED_LOGIN)` | 用户操作 overlay 时需要登录 | 打开登录界面，然后调用 `initToken()` |
| `onHandleMessage(NEED_PAY_ONG)` | 服务器返回 `PM402`（OnG 不足） | 打开充值界面 |
| `onHandleLiveViews(n)` | Socket 事件 `liveviews` | 显示观看人数（**已加上 230**） |
| `onShowITR(true)` | overlay 打开统计/dialog 部分 | 如需要可隐藏部分 app UI |
| `onFocusOverlay(takeControl = true, …)` | WebView 加载完成（`onPageFinished`） | 若 overlay 为 popup 则调整布局 |
| `onFocusOverlay(webViewError = true, …)` | 页面加载 / HTTP / SSL 错误 | 记录日志，可提示用户 |
| `onFocusOverlay(takeControl = false, …)` | overlay 被移除（`INTERACTIVE_HIDE_ANALYTICS`） | 恢复布局 |

## 4. `PlayerChangeListener`

<Tabs>
  <TabItem label="Kotlin">
```kotlin

    suspend fun currentPosition(): Long

```
  </TabItem>
  <TabItem label="Java">
```java

    long currentPosition();

```
  </TabItem>

`playbackState` 遵循 ExoPlayer 的约定：`1 = IDLE`，`2 = BUFFERING`，`3 = READY`，`4 = ENDED`。
SDK 映射为：`1 → "idle"`，`3 → isPlaying ? "playing" : "paused"`，其余 → `""`。

## 5. `OverlayView`

自定义的 `ConstraintLayout`，是承载所有 overlay 的**容器**。

| 公开成员 | 描述 |
|---|---|
| `overlayList: HashMap<OverlayWebView, OverlayConfig>` | 当前挂载的 WebView |
| `addListener(eventListener, overlayListener)` | SDK 在 `OverlayManager.init` 中自动调用 |
| `getCurrentOrientation(): Int` | 当前屏幕方向 |
| `getLastOverlay(): OverlayWebView?` | 最近挂载的 WebView |
| `getOverlayConfig(): OverlayConfig?` | popup 形式 overlay 的配置（如有） |
| `removeWebView(view)`、`removeWebViews()`、`clearViews()` | 移除 view 并销毁对应 tracking |

app 只需在 XML 中声明该 view；其余函数由 SDK 使用。

## 6. 主要 Model

### `Overlay` — 描述单个 overlay

| 字段 | 类型 | 含义 |
|---|---|---|
| `src` | `String` | web 模板 URL |
| `metadata` | `Metadata(pos, size)` | 按比例计算的位置 + 尺寸 |
| `duration` | `Long` | 显示时长（秒） |
| `targets` | `String?` | 适用平台（`all`、`androidmobile`、`androidtv`…） |
| `timelineId` | `String?` | 剧情节点标识（用于去重、防止重复回答） |
| `mediaContentId` | `String?` | 适用的内容 |
| `typeTimeline` | `Int?` | 0/1/2 小游戏，3 预测，4 头条，5 幸运 |
| `isPopupOverlay` | `Boolean` | `true` → 使用 9 个位置的 popup 约束；`false` → 上/下 inline 展示 |
| `allowAnonymous` | `Boolean` | 是否允许未登录用户查看/互动 |
| `requiredFanClub` | `Boolean?` | 是否要求 fanclub 身份 |
| `startTimeShowOverlay` | `Long?` | （VOD）开始显示的秒数 |
| `requiredFocus`、`frequencyLimit`、`ts`、`sendTime`、`serverTime` | | 来自服务器的辅助字段 |

## 7. Socket.IO 事件

### 7.1. Server → SDK（监听）

| 事件名 | 常量 | 数据类型 | 处理方式 |
|---|---|---|---|
| `overlay` | `Const.OVERLAY` | `JSONObject` | 实时 overlay |
| `ex-overlay` | `Const.EX_OVERLAY` | `JSONObject` | 补发 overlay（若 `duration <= 10` 则丢弃） |
| `overlay-recall` | `Const.OVERLAY_RECALL` | `JSONObject` \| `ByteArray` | 按 `timelineId` 撤回 overlay |
| `predict-timeline` | `Const.PREDICT_TIMELINE` | `ByteArray` | `ACTIVE` / `INACTIVE` / `POWER` / `END` |
| `lucky-event` | `Const.LUCKY_EVENT` | `ByteArray` | `ACTIVE` / `INACTIVE` / `POWER` / `END` |
| `predict-result` | `Const.PREDICT_RESULT` | `ByteArray` | `answer1` / `answer2` 数值 |
| `update-result` | `Const.UPDATE_RESULT` | `ByteArray` | 通过 `UPDATE_DATA_INTERACTIVE` 推送到 web |
| `liveviews` | `Const.LIVE_VIEWS` | `JSONObject` | 观看人数 |
| `data` | `Const.FAN_CLUB` | `ByteArray` | fanclub 状态 |
| `ckst` | `Const.CKST` | `JSONObject` | 服务器询问 player 状态 |

### 7.2. SDK → Server（emit）

| 名称 | 何时触发 | Payload |
|---|---|---|
| `join-room` | socket 连接后 | `{deviceId, mediaContentId, os, versionSDK, tenantId, isActivelyDisconnectSocket}` |
| `leave-room` | `leaveRoom()` | 同上 |
| `receive-message` | payload 带有 `traceLock = true` | 原始 payload（ByteArray UTF-8） |
| `emit-ack` | 各 tracking 节点 | 参见 [05 — Tracking](05-tracking-emit-ack.md) |
| `ckst` | 响应 `ckst` 事件 | `{action: "CHECK_PLAYER_STATUS", sessionId, data: {deviceId, os, mediaContentId, playerStatus}}` |

### 7.3. 连接 socket 时的 Header

| Header | 值 |
|---|---|
| `X-TENANT-ID` | `tenantId` |
| `v` | `BuildConfig.BUILD_VERSION`（SDK 构建日期） |
| `os` | `BuildConfig.DEVICE_TYPE`（`androidmobile` / `androidtv`） |
| `deviceId` | `Settings.Secure.ANDROID_ID` |
| `Authorization` | `Bearer <jwt>` 或原样传递的 cookie |

连接选项：仅使用 `websocket`，自动重连，延迟 5000ms（`reconnectionDelay` 与
`reconnectionDelayMax` 均为此值），`randomizationFactor = 0.4`。

## 8. HTTP Endpoint

Base URL = `Const.INTERACTIVE_URL`（由 `EnvInteractive` 推导得出）。
`BaseRequest` 的 Interceptor 会自动添加 header `X-TENANT-ID`。

| Method | 路径 | Header | 用途 |
|---|---|---|---|
| `GET` | `/api/ctc/scenario/v2/vod/{mediaContentId}/{os}` | `Authorization` | 加载 VOD 剧情 |
| `GET` | `/api/scenario/getActiveOverlay/{mediaContentId}` | — | 获取当前生效的 overlay（补发） |
| `POST` | `/api/actions` | `Authorization` | 发送操作 / 回答 |
| `GET` | `/api/public/vip-status` | `Authorization` | 回答前检查 VIP 状态 |
| `GET` | `/api/media/interactive-status/{mediaId}` | `x-tenant-id`、`Cookie` | 该内容是否支持互动 |

**`/api/actions` 请求体**（SDK 在 web 发送的 JSON 基础上补充）：

```jsonc
{
  "type": "INTERACTIVE_ACTION_REPORT",
  "deviceId": "<android-id>",      // SDK 添加
  "os": "(os, androidmobile)",     // SDK 添加
  "data": {
    "timelineId": "...",
    "typeTimeline": 1,
    "betAmount": 0,
    "allowAnonymous": false,
    "requiredFanClub": false,
    "media": "<mediaId>",          // SDK 添加
    "socket_id": "<socket id>"     // SDK 添加（仅 Live 时）
    // ...其余字段由 web 模板发送
  }
}
```

## 9. JS bridge 协议

Interface 名称：**`Android`**（`Const.JS_INTERFACE_NAME`）。

### Web → SDK

```javascript
Android.postMessage(JSON.stringify({ key: "LOADED_OVERLAY" }));
Android.postMessage(JSON.stringify({ type: "INTERACTIVE_ACTION_REPORT", data: {...} }));
```

| 值 | 常量 | 含义 |
|---|---|---|
| `key = LOADED_OVERLAY` | `Const.LOADED_OVERLAY` | 模板已准备好接收数据 |
| `type = INTERACTIVE_SHOW_ANALYTICS` | | overlay 显示 |
| `type = INTERACTIVE_HIDE_ANALYTICS` | | overlay 关闭 |
| `type = INTERACTIVE_ACTION_REPORT` | | 回答 / 操作（广告时带 `data.action = "CLICK_ADS"`） |
| `type = INTERACTIVE_OPEN_ANALYTICS` | | 打开 predict/lucky dialog |
| `type = INTERACTIVE_CLOSE_ANALYTICS` | | 关闭 predict/lucky dialog |

### SDK → Web

```javascript
window.addEventListener("message", (e) => { /* e.data 包含 key + data */ });
```

| `key` | 内容 |
|---|---|
| `GET_DATA_INTERACTIVE` | 初始 overlay 数据 |
| `UPDATE_DATA_INTERACTIVE` | 实时更新结果 |
| `UPDATE_CONFIRM` | 确认回答成功 |
| `UPDATE_COUTER` | predict 数据（`answer1`、`answer2`） |
| `UPDATE_NUMBER_LUCKY` | lucky 结果 |

## 10. 附加到模板 URL 的 query 参数

| 参数 | 何时添加 |
|---|---|
| `os=<deviceType>` | 若 `src` 尚未包含 `&os` |
| `logged=false` | 未登录**且** overlay 不允许 `allowAnonymous` |
| `duration=<剩余秒数>` | 总是添加（根据 `missTime` 计算） |
| `fanclub=false` | overlay 要求 fanclub 但用户尚未加入 fanclub |
| `u=<userId>` | 仅 `PredictDialog` / `LuckyDialog` |
| `timelineId`、`tenantId`、`deviceType`、`os` | 仅 VOD overlay（在 `parseTimeLineListForVOD` 中构建） |

## 12. 提示 Dialog（`SuggestType`）— SDK 自动显示

| 类型 | 显示内容 | 触发条件 |
|---|---|---|
| `SUGGEST_FAN_CLUB` | 提示需要加入 fanclub（附带 `Const.BJ_NAME`） | overlay `requiredFanClub` |
| `SUGGEST_BET` | “您是否同意使用 N OnG 来回答？” | `betAmount > 0` 且非 VIP |
| `SUGGEST_ANSWER_REJECT` | 来自 API 的 `description`，默认为“回答失败！” | API 返回 `success = false` |
| `SUGGEST_ANSWER_PAYMENT_REJECT` | “请充值 OnG！” | 错误码 `PM402` |
| `SUGGEST_PREDICT_END` | “预测已结束！” | predict `END` 事件 |
| `SUGGEST_LUCKY_END` | “活动已结束！” | lucky 结束 |
| `SUGGEST_ANSWER_SUCCESS`、`SUGGEST_ERROR_OCCUR`、`SUGGEST_LOGIN` | 已定义，当前流程尚未使用 | |
